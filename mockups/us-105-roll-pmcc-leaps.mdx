# US-105: Roll the PMCC LEAPS

_Open the **XYZ** PMCC detail page, then use **Roll LEAPS**. Same right-hand sheet as US-104's short-call roll, with the legs inverted: the trader **sells to close** the current LEAPS and **buys to open** a replacement further out. Two numbers move in opposite directions and both are on the sheet — the net cash (usually a debit, because time value is being bought) and the effective share cost, which re-anchors to the replacement strike._

## Where this appears

- **Position detail header** — the Roll LEAPS action, beside Roll Short Call.
- **Roll LEAPS sheet** — current LEAPS, open short call as coverage context, replacement inputs, live net preview.
- **Cost-basis panel and history** (US-103) — receives one net line per roll and re-anchors the effective share cost; this mockup shows the resulting row, it does not redefine the panel.

## The coverage ruler, inverted

US-104's ruler asked "does the LEAPS still cover the replacement short?" This one asks the mirror question: "does the replacement LEAPS still cover the open short?" Today, the short, the current LEAPS, and the replacement sit on one axis. The replacement may land before the current LEAPS (coverage shortens — advisory) but never on or before the short (US-102 — blocked).

## Acceptance Criteria States

- **entry**: the sheet opens with the current LEAPS at 70 DTE, the $112 short at 7 DTE as read-only coverage, cost basis $21.80, effective share cost $101.80. No preview until proceeds and debit are filled.
- **roll-up-out**: $85 replacement, Jan 21 2028, $26.00 proceeds, $23.50 debit. Net Credit $2.50 per share ($250.00), Roll Up & Out, 196 DTE. Cost basis after $19.30; effective share cost after $104.30, up $2.50 — the cash came out, the strike moved up more.
- **roll-out-debit**: same $80 strike, Jan 21 2028, $29.20 debit. Net Debit $3.20 ($320.00), Roll Out. Basis $25.00, effective $105.00. Confirm stays available — paying to extend coverage is the normal case.
- **too-much-time**: same $80 strike rolled to Jan 19 2029 at $37.00. Net Debit $11.00. Effective share cost after $112.80 sits above the $112 short strike — advisory warning, roughly $0.80 per share of loss if assigned. Confirm stays available.
- **strike-above-short**: $112 replacement. Blocked: the LEAPS strike must stay below the open short strike or the position is no longer a PMCC.
- **uncovers-short**: a Jul 16 2027 replacement expires with the short call. Blocked by the US-102 comparator, ruler goes red, nothing is recorded.
- **shortens-coverage**: an Aug 20 2027 replacement is 42 DTE, 28 days shorter than the current LEAPS, but still past the short. Allowed, with an advisory note.
- **no-change**: same strike, same expiration. Blocked.
- **zero-proceeds**: $0.00 proceeds from close. Blocked at the field.
- **recorded**: the linked leg pair is written (SELL CALL $80 → BUY CALL $85), cost basis moves $21.80 to $19.30, LEAPS cost to date $25.00 to $22.50, one net history line, effective share cost re-anchored to $85 + $19.30.
- **no-short-call**: the short expired on Jul 16. The coverage and strike checks are skipped — an uncovered LEAPS has no naked-call risk — and the roll records normally.

export function evaluate(draft, shortOpen, today) {
  const proceeds = draft.proceeds === '' ? null : Number(draft.proceeds)
  const debit = draft.debit === '' ? null : Number(draft.debit)
  const strike = draft.strike === '' ? null : Number(draft.strike)
  const expiration = draft.expiration === '' ? null : draft.expiration
  const errors = {}

  if (shortOpen && expiration !== null && expiration <= SHORT.expiration) {
    errors.expiration = 'LEAPS call must expire after the short call.'
  }
  if (shortOpen && strike !== null && strike >= SHORT.strike) {
    errors.strike = `LEAPS strike must be below the short-call strike ($${SHORT.strike.toFixed(2)}).`
  }
  if (proceeds !== null && proceeds <= 0) {
    errors.proceeds = 'Proceeds from close must be greater than zero'
  }
  if (debit !== null && debit <= 0) {
    errors.debit = 'Replacement debit must be greater than zero'
  }
  if (strike === LEAPS.strike && expiration === LEAPS.expiration) {
    errors.form = 'Roll must change the strike, the expiration, or both'
  }

  const priced = proceeds !== null && debit !== null && proceeds > 0 && debit > 0
  const net = priced ? proceeds - debit : null
  const postBasis = priced ? BASIS - net : null
  const effectiveAfter = priced && strike !== null ? strike + postBasis : null
  const effectiveBefore = LEAPS.strike + BASIS
  const complete = proceeds !== null && debit !== null && strike !== null && expiration !== null
  const valid = complete && Object.keys(errors).length === 0
  const shortfall =
    valid && shortOpen && effectiveAfter > SHORT.strike ? effectiveAfter - SHORT.strike : null
  const shortened =
    valid && expiration < LEAPS.expiration
      ? dte(LEAPS.expiration, today) - dte(expiration, today)
      : null

  return {
    proceeds,
    debit,
    strike,
    expiration,
    errors,
    net,
    postBasis,
    effectiveBefore,
    effectiveAfter,
    valid,
    shortfall,
    shortened
  }
}

export function rollLabel(strike, expiration) {
  const direction = strike > LEAPS.strike ? 'Up' : strike < LEAPS.strike ? 'Down' : null
  const timing =
    expiration > LEAPS.expiration ? 'Out' : expiration < LEAPS.expiration ? 'In' : null
  const parts = [direction, timing].filter(Boolean)
  if (parts.length === 0) return null
  const strikeText =
    direction === null
      ? `same $${LEAPS.strike} strike`
      : `$${LEAPS.strike} to $${strike} strike`
  const dateText =
    timing === null
      ? `same ${monthYearOf(LEAPS.expiration)} expiration`
      : `${monthYearOf(LEAPS.expiration)} to ${monthYearOf(expiration)} expiration`
  return `Roll ${parts.join(' & ')}: ${strikeText}, ${dateText}`
}

export function CoverageRuler({ proposed, blocked, shortOpen, today }) {
  const currentDte = dte(LEAPS.expiration, today)
  const proposedDte = proposed === null ? null : dte(proposed, today)
  const span = Math.max(currentDte, proposedDte ?? 0)
  const pct = (days) => `${Math.max(0, Math.min((days / span) * 100, 100))}%`
  const tone = blocked ? 'var(--wb-red)' : 'var(--wb-gold)'

  return (
    <div className="flex flex-col gap-3 px-4 py-4">
      <div className="relative h-10">
        <div className="absolute inset-x-0 top-4 h-px bg-wb-border" />
        <div
          className="absolute top-4 h-px"
          style={{ left: 0, width: pct(proposedDte ?? currentDte), background: tone }}
        />
        <div className="absolute top-2.5 h-3 w-px bg-wb-text-muted" style={{ left: 0 }} />
        {shortOpen ? (
          <div
            className="absolute top-2.5 h-3 w-px bg-wb-text-secondary"
            style={{ left: pct(dte(SHORT.expiration, today)) }}
          />
        ) : null}
        <div
          className="absolute top-2.5 h-3 w-0.5 bg-wb-green opacity-60"
          style={{ left: pct(currentDte) }}
        />
        {proposedDte === null ? null : (
          <div
            className="absolute top-1 h-6 w-0.5"
            style={{ left: pct(proposedDte), background: tone }}
          />
        )}
      </div>
      <div className="flex flex-col gap-1.5 text-[10px] text-wb-text-muted">
        <LegendItem swatch="h-3 w-px bg-wb-text-muted" label="Today" value={today} />
        {shortOpen ? (
          <LegendItem
            swatch="h-3 w-px bg-wb-text-secondary"
            label="Open short call"
            value={`${SHORT.expiration} · ${dte(SHORT.expiration, today)} DTE`}
          />
        ) : (
          <LegendItem swatch="h-3 w-px bg-transparent" label="Open short call" value="none" />
        )}
        <LegendItem
          swatch="h-3 w-0.5 bg-wb-green opacity-60"
          label="Current LEAPS (selling)"
          value={`${LEAPS.expiration} · ${currentDte} DTE`}
        />
        <LegendItem
          swatch="h-4 w-0.5"
          swatchStyle={{ background: tone }}
          label="Replacement LEAPS (buying)"
          value={proposedDte === null ? 'not entered' : `${proposed} · ${proposedDte} DTE`}
          tone={blocked ? 'text-wb-red' : undefined}
        />
      </div>
      {proposedDte === null ? (
        <p className="text-[11px] text-wb-text-secondary">
          Current LEAPS expires in {currentDte} days — inside the window where its time value starts
          to decay fast.
          {shortOpen ? ` The open short call needs cover past ${SHORT.expiration}.` : ''}
        </p>
      ) : blocked ? (
        <p className="text-[11px] text-wb-red">
          The replacement LEAPS expires on or before the short call. Past this point the short call
          is naked.
        </p>
      ) : (
        <p className="text-[11px] text-wb-text-secondary">
          Replacement LEAPS at {proposedDte} DTE
          {shortOpen ? `, ${proposedDte - dte(SHORT.expiration, today)} days past the short call` : ''}
          .
        </p>
      )}
    </div>
  )
}

                          readOnly
                          hasError={model.errors.expiration !== undefined}
                        />
                      </Field>
                      <Field label="Fill date" htmlFor="leaps-fill-date">
                        <NumberInput id="leaps-fill-date" value={today} readOnly />
                      </Field>
                      <p className="text-[10px] text-wb-text-muted">
                        Prototype: fields are read-only here. Use the review controls below the
                        frame to load each case.
                      </p>
                    </div>
                  </SectionCard>

                  {model.net === null ? (
                    <div className="rounded border border-dashed border-wb-border p-4 text-center text-xs text-wb-text-muted">
                      Enter the proceeds from close and the replacement debit to preview the net.
                    </div>
                  ) : (
                    <SectionCard header="Net" headerVariant="emphasized">
                      <div className="flex flex-col gap-3 px-4 py-4">
                        <div className="flex items-baseline justify-between">
                          <span className="text-xs uppercase tracking-widest text-wb-text-muted">
                            {isDebit ? 'Net Debit' : 'Net Credit'}
                          </span>
                          <span
                            className={`text-xl font-semibold ${isDebit ? 'text-wb-red' : 'text-wb-green'}`}
                          >
                            {money(Math.abs(model.net))}
                            <span className="ml-1 text-xs text-wb-text-muted">/ share</span>
                          </span>
                        </div>
                        <SummaryRow
                          label="Total"
                          value={`${money(Math.abs(model.net) * 100 * CONTRACTS)} (${CONTRACTS} contract)`}
                        />
                        {label ? (
                          <div className="rounded bg-wb-bg-elevated px-3 py-2 text-[11px] text-wb-text-secondary">
                            {label}
                          </div>
                        ) : null}
                        <SummaryRow
                          label="Cost basis after roll"
                          value={`$${model.postBasis.toFixed(2)} / share`}
                        />
                        {model.effectiveAfter === null ? null : (
                          <>
                            <SummaryRow
                              label="Effective share cost after roll"
                              value={`$${model.effectiveAfter.toFixed(2)}`}
                              highlight
                            />
                            <p className="text-[11px] leading-relaxed text-wb-text-muted">
                              {`$${model.strike.toFixed(2)} strike + $${model.postBasis.toFixed(2)} basis · ${
                                effectiveDelta === 0
                                  ? 'unchanged'
                                  : `${effectiveDelta > 0 ? 'up' : 'down'} ${money(Math.abs(effectiveDelta))} from $${model.effectiveBefore.toFixed(2)}`
                              }. ${
                                isDebit
                                  ? 'You are buying time value; it lands in the basis.'
                                  : 'Cash came out, but the strike moved up more than the credit.'
                              }`}
                            </p>
                          </>
                        )}
                      </div>
                    </SectionCard>
                  )}

                  {model.shortfall !== null ? (
                    <AlertBox variant="warning">
                      {`Open short strike $${SHORT.strike.toFixed(2)} is below your effective share cost of $${model.effectiveAfter.toFixed(2)} after this roll. If assigned, covering from the LEAPS realizes roughly $${model.shortfall.toFixed(2)} per share of loss. You can still record it.`}
                    </AlertBox>
                  ) : null}

                  {model.shortened !== null ? (
                    <AlertBox variant="info">
                      {`Replacement LEAPS is ${dte(model.expiration, today)} DTE, ${model.shortened} days shorter than the current LEAPS.${shortOpen ? ' It still covers the open short call.' : ''}`}
                    </AlertBox>
                  ) : null}

                  {model.errors.form ? (
                    <AlertBox variant="error">{model.errors.form}</AlertBox>
                  ) : null}
                </SheetBody>
                <SheetFooter>
                  <div className="flex w-full flex-col gap-3">
                    {blockedByCoverage || model.errors.strike ? (
                      <p className="text-[11px] leading-relaxed text-wb-red">
                        The XYZ $80.00 LEAPS stays open at {LEAPS.expiration}. No close or replacement
                        leg is recorded.
                      </p>
                    ) : null}
                    <div className="grid grid-cols-2 gap-3">
                      <FormButton label="Cancel" variant="secondary" onClick={close} />
                      <div className={model.valid ? undefined : 'cursor-not-allowed opacity-40'}>
                        <FormButton
                          label="Confirm roll"
                          disabled={!model.valid}
                          onClick={confirm}
                        />
                      </div>
                    </div>
                    <span className="text-[10px] text-wb-text-secondary">
                      Your draft is kept until the roll is valid. No order is placed.
                    </span>
                  </div>
                </SheetFooter>
              </div>
            </SheetPanel>
          </SheetOverlay>
        ) : null}
      </div>

      <details className="rounded-lg border border-wb-border p-3 text-xs text-wb-text-secondary">
        <summary className="cursor-pointer">Review states · prototype controls</summary>
        <div className="mt-3 flex flex-wrap gap-2">
          {PRESETS.map((entry) => (
            <FormButton
              key={entry.key}
              label={entry.label}
              variant={entry.key === presetKey && sheetOpen ? 'primary' : 'secondary'}
              onClick={() => choose(entry.key)}
            />
          ))}
          <FormButton
            label="recorded"
            variant={recorded ? 'primary' : 'secondary'}
            onClick={() => {
              setPresetKey('roll-up-out')
              setRecorded(true)
              setSheetOpen(false)
            }}
          />
          <FormButton
            label="no short call"
            variant={shortOpen ? 'secondary' : 'primary'}
            onClick={() => {
              setShortOpen(!shortOpen)
              setPresetKey('roll-up-out')
              setSheetOpen(true)
              setRecorded(false)
            }}
          />
        </div>
        <p className="mt-3">
          Every number in the sheet is derived, not hardcoded: the net is proceeds minus debit, the
          post-roll basis is $21.80 less that net, and the effective share cost is the replacement
          strike plus the post-roll basis. DTE counts from the {today} valuation date. Blocking
          cases dim confirm; the ruler turns red only when coverage is the problem. With no short
          call open the valuation moves to 2027-07-19 and the coverage and strike checks disappear.
          Escape, Cancel, or clicking outside dismisses without recording.
        </p>
      </details>
    </div>
  )
}
