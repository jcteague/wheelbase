# Epic 04: Position Card — Final Layout

_This mockup shows the unified position card after all dashboard stories are complete. Each card has four zones: **header** (ticker + phase), **stats grid** (strike, DTE, premium, cost basis), **distance gauge** (Phase 2 — live price vs. strike), and **footer** (expiration + navigation). The distance gauge replaces the Phase 1 "EXPIRING SOON" badge as a richer urgency signal; in Phase 1 builds, the gauge zone is omitted and DTE handles urgency via gold coloring._

## Story Contributions

- **US-18**: Card structure — header, stats grid, footer. Responsive grid layout.
- **US-22**: Distance-to-strike gauge zone between the stats and footer. Color thresholds for OTM/approaching/ITM.
- **US-24**: Hover border brightening, pointer cursor, "View →" in footer, keyboard focusable.

## Acceptance Criteria States

- **portfolio**: Full dashboard — summary bar (US-19), filter pills (US-20), sort control (US-21), five cards in mixed phases
- **otm-safe**: CSP comfortably OTM (+5.0%) — green gauge
- **approaching**: CC within 2% of strike — amber gauge, DTE gold
- **itm-danger**: CSP in-the-money (−4.0%) — red gauge, urgency
- **holding-shares**: No active option leg — no strike, no DTE, no distance gauge
- **no-live-price**: Phase 1 or price unavailable — distance zone hidden, DTE urgency badge inline
- **closed**: Completed wheel — muted card, final P&L shown instead of distance

export function distCalc(inst, strike, price) {
  if (!price || !strike) return null
  return ((price - parseFloat(strike)) / parseFloat(strike)) * 100
}

export function distIsOtm(inst, dist) {
  if (dist === null) return false
  return inst === 'PUT' ? dist > 0 : dist < 0
}

export function distColor(inst, dist) {
  if (dist === null) return T.textMut
  const otm = distIsOtm(inst, dist)
  const abs = Math.abs(dist)
  if (!otm) return T.red // ITM — danger
  if (abs <= 2) return T.gold // OTM but close — approaching
  if (abs <= 5) return T.green // OTM — safe
  return T.textSec // OTM by > 5% — comfortable, muted
}

export function distLabel(dist) {
  if (dist === null) return '—'
  const sign = dist >= 0 ? '+' : ''
  return `${sign}${dist.toFixed(1)}%`
}

export function distStatus(inst, dist) {
  if (dist === null) return null
  const otm = distIsOtm(inst, dist)
  if (!otm) return 'ITM'
  if (Math.abs(dist) <= 2) return 'NEAR'
  return 'OTM'
}

              <PositionCard key={pos.id} pos={pos} />
            ))}
          </div>
        ) : (
          <EmptyState />
        )}

      </div>
    </div>

)
