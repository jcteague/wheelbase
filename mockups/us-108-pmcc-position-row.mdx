# US-108: PMCC position row on the dashboard

_The dashboard positions list with **XYZ**, a PMCC, sitting between two classic wheels. The row keeps the ten shared columns; wherever a wheel row shows one value for its single open leg, the PMCC row stacks two lines — the LEAPS on top (`L`), the short call beneath it (`S`). Cost basis and credits come from US-103's cash ledger. Net P&L marks the open diagonal at the mid and subtracts that cost basis._

## Where this appears

- **Dashboard positions list** — the PMCC row, in DTE order with the wheels. The nearest decision point is the short call's expiration when one is open, otherwise the LEAPS expiration.
- **Position detail** — unchanged. Clicking the row opens the XYZ detail page as any other row does.
- **Management queue** — unchanged. Alerts live there (US-106, US-107); the row carries only the same in-row cues a wheel row has.

## Acceptance Criteria States

- **both-open**: 2026-11-06, XYZ $104.20. $80 LEAPS (315d) marked $26.10, $108 short (14d) marked $0.90. Spread value $2,520.00 less cost basis $2,120.00 = **+$400.00, +18.9% of basis**. The short has given back 50.0% of its $1.80 credit, so the TARGET badge fires exactly as it does on a wheel row.
- **stock-fell**: XYZ $92.00. The LEAPS is marked $16.40 while the short is nearly worthless at $0.20: the diagonal is **-$500.00** even though the short leg is 88.9% profitable. Two greens on one leg, one red on the position.
- **wide-spread**: LEAPS quoted $24.60 × $27.60 — 11.5% of mid. The mid carries the existing wide-spread warning and the P&L is flagged as unreliable, because a far-dated deep ITM LEAPS mid is the least trustworthy number on the row.
- **leaps-quote-missing**: no LEAPS snapshot this poll. The short mid still shows; the P&L reads — rather than a half-marked figure.
- **leaps-only**: 2026-10-19, the first short expired worthless three days ago and nothing has been sold yet. Short cells read "No short call open"; the row sorts by the LEAPS DTE; P&L is the LEAPS mark alone against the $2,300.00 basis.
- **roll-window**: 2027-07-20, the LEAPS has 59 days left. Its DTE turns gold — the same treatment the US-107 alert threshold uses — while the 31-day short stays neutral.
- **free**: after a LEAPS roll to $85 and eleven short-call cycles, credits ($22.90) exceed the LEAPS cost to date ($22.50). Cost basis reads **-$40.00** with "LEAPS paid for"; P&L shows the dollar figure only, because a percentage of a negative basis means nothing.
- **three-contracts**: the both-open state with three contracts per leg. Every total scales by three; every per-share figure and percentage is unchanged.
- **closed**: a PMCC that has been closed (US-111 or a later close story). It sits in the Closed section, muted, with its last cost basis and credits and no live figures.

Use the preset controls under the frame. Every figure in the row is derived from the preset's quotes, fills and valuation date, so the mockup cannot drift from the criteria.

export const PROFIT_TARGET_PERCENT = 50
export const LEAPS_ROLL_WINDOW_DTE = 60
export const SHORT_URGENT_DTE = 7
export const SHARES = 100

export const money = (value) => {
  const abs = Math.abs(value).toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 })
  return value < 0 ? `-$${abs}` : `$${abs}`
}

export const signed = (value) => (value >= 0 ? `+${money(value)}` : money(value))

export const pct1 = (value) => `${value.toFixed(1)}%`

export const dte = (expiration, today) =>
  Math.round((Date.parse(expiration) - Date.parse(today)) / 86400000)

export const addDays = (today, days) =>
  new Date(Date.parse(today) + days * 86400000).toISOString().slice(0, 10)

export const mid = (leg) => (leg && leg.bid !== null ? Math.round(((leg.bid + leg.ask) / 2) * 100) / 100 : null)

export const wideSpread = (leg) => {
  const m = mid(leg)
  return m !== null && m > 0 && (leg.ask - leg.bid) / m > 0.1
}

export function evaluate(preset) {
  const shares = SHARES * preset.contracts
  const basisPerShare = Math.round((preset.leapsCost - preset.credits) * 100) / 100
  const basisTotal = basisPerShare * shares
  const creditsTotal = preset.credits * shares
  const recovered = preset.leapsCost > 0 ? (preset.credits / preset.leapsCost) * 100 : null
  const leapsMid = mid(preset.leaps)
  const shortMid = preset.short ? mid(preset.short) : null
  const shortOpen = preset.short !== null
  const marksReady = !preset.closed && leapsMid !== null && (!shortOpen || shortMid !== null)
  const valuePerShare = marksReady ? leapsMid - (shortOpen ? shortMid : 0) : null
  const pnl = marksReady ? Math.round((valuePerShare * shares - basisTotal) * 100) / 100 : null
  const pnlPercent = pnl !== null && basisTotal > 0 ? (pnl / basisTotal) * 100 : null
  const shortPnl = shortOpen && shortMid !== null && !preset.closed ? (preset.short.sold - shortMid) * shares : null
  const shortPercent = shortPnl !== null ? (shortPnl / (preset.short.sold * shares)) * 100 : null
  const leapsDte = dte(preset.leaps.expiration, preset.today)
  const shortDte = shortOpen ? dte(preset.short.expiration, preset.today) : null
  return {
    shares,
    basisPerShare,
    basisTotal,
    creditsTotal,
    recovered,
    leapsMid,
    shortMid,
    shortOpen,
    marksReady,
    valuePerShare,
    pnl,
    pnlPercent,
    shortPnl,
    shortPercent,
    targetReached: shortPercent !== null && shortPercent >= PROFIT_TARGET_PERCENT,
    leapsDte,
    shortDte,
    sortDte: preset.closed ? null : shortOpen ? shortDte : leapsDte,
    leapsWide: wideSpread(preset.leaps),
    free: basisPerShare <= 0,
    state: preset.closed ? 'Closed' : shortOpen ? 'LEAPS + short call open' : 'LEAPS open · no short call'
  }
}

export function Derivation({ preset, model }) {
  const rows = [
    ['LEAPS mid', model.leapsMid === null ? '— (no snapshot)' : money(model.leapsMid)],
    ['Short mid', !model.shortOpen ? 'no short call open' : model.shortMid === null ? '—' : money(model.shortMid)],
    ['Spread value / share', model.valuePerShare === null ? '—' : `${money(model.valuePerShare)} × ${model.shares} sh = ${money(model.valuePerShare * model.shares)}`],
    ['Cost basis (US-103)', `${money(preset.leapsCost)} LEAPS cost − ${money(preset.credits)} credits = ${money(model.basisPerShare)} / share · ${money(model.basisTotal)}`],
    ['Net P&L', model.pnl === null ? '— (needs both marks)' : `${money(model.valuePerShare * model.shares)} − ${money(model.basisTotal)} = ${signed(model.pnl)}${model.pnlPercent === null ? ' (no % — basis ≤ 0)' : ` · ${pct1(model.pnlPercent)} of basis`}`],
    ['Short call % of max', model.shortPercent === null ? '—' : `(${money(preset.short.sold)} − ${money(model.shortMid)}) / ${money(preset.short.sold)} = ${pct1(model.shortPercent)}${model.targetReached ? ' → TARGET' : ''}`],
    ['Premium recovered', model.recovered === null ? '—' : `${money(preset.credits)} / ${money(preset.leapsCost)} = ${pct1(model.recovered)}`],
    ['Sort key (DTE)', model.sortDte === null ? 'closed → last' : `${model.sortDte}d (${model.shortOpen ? 'short call' : 'LEAPS'})`]
  ]
  return (
    <SectionCard header="How the row is derived">
      <div className="grid grid-cols-[180px_1fr] gap-x-6 gap-y-2 p-4 font-wb-mono text-xs">
        {rows.map(([label, value]) => (
          <div key={label} className="contents">
            <span className="text-wb-text-muted">{label}</span>
            <span className="text-wb-text-primary">{value}</span>
          </div>
        ))}
      </div>
    </SectionCard>
  )
}

          <span className="text-xs text-wb-text-muted">Valuation date {preset.today} · America/New_York</span>
        </div>
        <div className="px-6 pt-4 pb-2 text-xs font-medium uppercase tracking-[0.08em] text-wb-text-muted">Active</div>
        <table className="w-full border-collapse text-[0.8125rem]">
          <thead>
            <tr className="bg-wb-bg-surface border-b border-wb-border">
              {COLUMNS.map((col) => (
                <TableHeader key={col} className="px-[16px] py-[8px]">
                  {col}
                </TableHeader>
              ))}
            </tr>
          </thead>
          <tbody>
            {active.map((row) =>
              row.kind === 'wheel' ? (
                <WheelRow key={row.w.ticker} wheel={row.w} today={preset.today} />
              ) : (
                <PmccRow key="pmcc" preset={preset} model={model} />
              )
            )}
          </tbody>
        </table>
        {preset.closed ? (
          <>
            <div className="px-6 pt-4 pb-2 text-xs font-medium uppercase tracking-[0.08em] text-wb-text-muted">Closed</div>
            <table className="w-full border-collapse text-[0.8125rem]">
              <tbody>
                <PmccRow preset={preset} model={model} />
              </tbody>
            </table>
          </>
        ) : null}
        <div className="h-4" />
      </div>
      <div className="flex flex-wrap gap-2">
        {PRESETS.map((p) => (
          <button
            key={p.key}
            type="button"
            onClick={() => setKey(p.key)}
            className={`rounded-md border px-3 py-1.5 text-xs ${p.key === key ? 'border-wb-gold bg-wb-gold-dim text-wb-gold' : 'border-wb-border bg-wb-bg-surface text-wb-text-secondary'}`}
          >
            {p.label}
          </button>
        ))}
      </div>
      <Derivation preset={preset} model={model} />
    </div>
  )
}
