# US-66: Screener Results

_As a wheel trader, I want a ranked, scannable table of candidate strikes so I can compare put-selling entries across tickers at a glance._

## Acceptance Criteria States

- **ranked** — the surviving candidates, one recommended put strike per ticker, ranked by **yield-per-delta** (annualized return-if-flat ÷ delta). KO (0.71) sorts above AAPL (0.53) above MSFT (0.50). MSFT's IV rank reads `n/a` because the volatility service returned no data — the candidate is still ranked. The `Excluded (4)` section sits collapsed below.
- **earnings** — earnings handling set to `Flag only`: AAPL carries an `Earnings Jul 31 · 21d before expiry` warning and drops below the clean rows; NVDA shows a neutral `Earnings date unknown` caution. In the default `Exclude` mode these instead move into the Excluded section.
- **excluded** — the `Excluded (4)` section expanded, each candidate paired with its machine-readable reason (spread, delta band, open interest, no options listed).
- **unavailable** — Massive couldn't be reached on the last refresh. A distinct "market data unavailable" state — **not** the same as "no candidates".
- **empty** — screening ran and nothing survived the criteria. Visually distinct from a provider outage.
- **stale** — market CLOSED: the table renders but is badged as a stale snapshot with the quote time, since after-hours option marks are unreliable.

Colors, fonts, and chrome are driven by the app's design tokens in `src/renderer/src/index.css` (`--wb-*`). The market-status pill mirrors `MarketStatusPill` (LIVE/CLOSED). Yield math is internally consistent: `period = mark / strike`, `annualized = period × 365 / DTE`, `score = annualized ÷ delta`.

            )}

            {state === 'ranked' ? (
              <div style={{ fontFamily: T.mono, fontSize: '0.7rem', color: T.muted, lineHeight: 1.6 }}>
                No price ceiling applied (off by default) — large-cap names appear.
              </div>
            ) : null}

            <ExcludedSection open={open} onToggle={() => setExcludedOpen((v) => !v)} />
          </div>
        )}
      </Shell>
    </div>
  )
}
