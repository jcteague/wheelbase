# US-60: Expiration Calendar View

_As a wheel trader planning my week, I want a color-coded expiration calendar so I can see when management work is clustering._

## Acceptance Criteria States

- **grid** — populated month view with expirations rendered on date cells using phase colors; clicking a populated date opens the day-detail panel (ticker, phase, strike, DTE); the Aug 21 cluster demonstrates the `+2 more` overflow.
- **agenda** — alternative layout: a week-grouped timeline with a per-week density bar, built for spotting weeks where management work piles up.
- **heatmap** — alternative layout: a 14-day management-horizon strip where each day's workload is shaded by count.
- **empty** — clean empty state (applies to whichever layout is active).

All three layouts, colors, fonts, and chrome are driven directly by the app's design tokens in `src/renderer/src/index.css` (`--wb-*`) so the mockup tracks the real UI. Phase colors mirror `src/renderer/src/lib/phase.ts`. Positions in `HOLDING_SHARES` with no open option intentionally do not appear on the calendar.

export function heatTint(count) {
  if (count === 0) return 'transparent'
  const alpha = Math.min(0.06 + count * 0.05, 0.3)
  return `rgba(230,168,23,${alpha})`
}

  const cols = HORIZON.map((day) => ({ ...day, items: empty ? [] : (EXP[day.d] ?? []) }))
  const heaviest = empty
    ? null
    : cols.reduce((a, b) => (b.items.length > a.items.length ? b : a), cols[0])
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: 18 }}>

            }}
          >

                style={{

                  color: day.today ? T.gold : T.muted
                }}
              >

              <div
                style={{
                  fontFamily: T.mono,
                  fontSize: '0.85rem',
                  fontWeight: 700,
                  color: day.today ? T.gold : T.text
                }}
              >
                {day.d}
              </div>
            </div>
            {day.items.length ? (
              <div

                  fontFamily: T.mono,

          </span>
        </div>
      )}
    </div>
  )
}

export function Segment({ options, value, onChange }) {
  return (
    <div
      style={{
        display: 'inline-flex',
        gap: 2,
        padding: 3,
        borderRadius: 999,
        border: `1px solid ${T.border}`,
        background: T.elevated
      }}
    >
      {options.map((opt) => {
        const active = value === opt.v
        return (
          <button
            key={opt.v}
            onClick={() => onChange(opt.v)}
            style={{
              padding: '5px 12px',
              borderRadius: 999,
              border: 'none',
              cursor: 'pointer',
              fontFamily: T.mono,
              fontSize: '0.72rem',
              background: active ? 'var(--wb-gold-dim)' : 'transparent',
              color: active ? T.gold : T.text2,
              fontWeight: active ? 700 : 400
            }}
          >
            {opt.label}
          </button>
        )
      })}
    </div>
  )
}
