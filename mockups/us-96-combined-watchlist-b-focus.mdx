# Combined watchlist — B · Focus

Keep both watchlist sections in a compact left column and review one stock in detail on the right.

**Design proposal · fictional sample data as of Wednesday, September 9, 2026, 10:42 CT.** The last completed session is Tuesday, September 8 (Monday the 7th was Labor Day). Use the preview controls for no matches and an outage; add a stock, try a duplicate ticker, select stock details, or preview the trade handoff. No data is saved outside this mockup.

**IV-rank age (US-98).** Every IV rank sits beside a small **freshness ring** whose fill is a step function of the reading's tier, not the raw day count: full and green when fresh (0–1 sessions), three-quarters when aging (2–3), half and muted when stale (4–10), a quarter when expired (over 10, the value replaced by `exp`), and drawn empty in gold when the reading predates the stock's last earnings print. A ticker that was never collected reads `n/a` with no ring, so "collection has been failing" and "nothing was ever collected" stay distinguishable. Hover or focus a ring for a tooltip naming the tier, the value, the observed session, the age in trading days, and what the reading can and cannot decide. The rule this concept adds on top: **an unusable reading is an unknown, and an unknown never decides anything** — it cannot satisfy an `IVR ≥ N` condition, so the stock stays in Stocks of interest even when a qualifying put exists, and the reason says why. Aging readings still count. Sample rows: MSFT (aging), PEP (stale), DIS (expired), ORCL (predates earnings), XYZ (no reading).

**Implementation note.** The shipped `IvrCell` (US-98) renders `· Nd` text and a "predates earnings" caption and collapses an expired reading to `n/a`; it has no ring, no tooltip, and no `exp`. US-96 must extend that cell (and the IPC reading shape, which currently drops `expired`) so both the screener and this page draw the same ring from the same assessed reading. The ring and tooltip below are the target treatment.

export function isUsable(state) {
  return state === 'fresh' || state === 'aging'
}

export function FreshnessRing({ state, size }) {
  // Stroke colors are SVG attributes bound to wb tokens; fill is the tier's step, never the raw age.
  const px = size ?? 14
  const stroke = 2.25
  const r = (px - stroke) / 2
  const c = 2 * Math.PI * r
  const frac = RING_FILL[state]
  const earnings = state === 'predates_earnings'
  return (
    <svg
      width={px}
      height={px}
      viewBox={`0 0 ${px} ${px}`}
      className="block shrink-0"
      aria-hidden="true"
    >
      <circle
        cx={px / 2}
        cy={px / 2}
        r={r}
        fill="none"
        stroke={earnings ? 'var(--wb-gold)' : 'var(--wb-border)'}
        strokeWidth={stroke}
        strokeOpacity={earnings ? 0.45 : 1}
      />
      {frac > 0 && (
        <circle
          cx={px / 2}
          cy={px / 2}
          r={r}
          fill="none"
          stroke={RING_COLOR[state]}
          strokeWidth={stroke}
          strokeDasharray={`${frac * c} ${c}`}
          transform={`rotate(-90 ${px / 2} ${px / 2})`}
        />
      )}
      {earnings && <circle cx={px / 2} cy={px / 2} r={1.6} fill="var(--wb-gold)" />}
    </svg>
  )
}

export function tooltipCopy(ticker, reading) {
  const value = Number(reading.value)
  const observed = easternSession.format(new Date(reading.observedAt))
  const days =
    reading.ageTradingDays === 1 ? '1 trading day' : reading.ageTradingDays + ' trading days'
  if (reading.state === 'predates_earnings')
    return `Observed ${observed} at the close. ${ticker} reported earnings after that reading. IV re-prices through a print, so this reading is unusable regardless of age — it cannot satisfy an IV condition or the IV-rank floor.`
  if (reading.state === 'expired')
    return `Last reading ${days} ago (${observed}). Treated as no reading: shows exp, never decides a condition, never applies the IV-rank floor. Age this old means collection has been failing for ${ticker}.`
  if (reading.state === 'stale')
    return `IV rank ${value}, observed ${observed} — ${days} old. Too old to trust: shown for context but cannot satisfy an IV condition or the IV-rank floor. ${ticker} still ranks on yield-per-delta.`
  if (reading.state === 'aging')
    return `IV rank ${value}, observed ${observed} — ${days} old. Still decision-usable and still counts toward conditions and the floor; expect it to have drifted a few points.`
  return `IV rank ${value}, observed ${observed} at the close — ${days} old. Current as of the last session close.`
}

export function IvrReading({ ticker, reading, large }) {
  // The shared cell: numeral + ring, tooltip on hover or keyboard focus. n/a has no ring.
  // The tooltip is fixed to the viewport (cards clip overflow), placed from the cell's box on open.
  const anchor = useRef(null)
  const [pos, setPos] = useState(null)
  const numeral = large ? 'font-wb-mono text-lg' : 'font-wb-mono text-[11px] font-semibold'
  if (reading === null)
    return (
      <span className={numeral + ' font-normal text-wb-text-muted'} title="No IV rank collected">
        n/a
      </span>
    )
  const expired = reading.state === 'expired'
  const tone = isUsable(reading.state) ? 'text-wb-text-primary' : 'text-wb-text-muted'
  const body = tooltipCopy(ticker, reading)
  function show() {
    const box = anchor.current.getBoundingClientRect()
    setPos({ top: box.top - 8, right: window.innerWidth - box.right })
  }
  function hide() {
    setPos(null)
  }
  return (
    <span
      ref={anchor}
      className="relative inline-flex cursor-default items-center gap-1.5"
      tabIndex={0}
      aria-label={TIER_TITLE[reading.state] + '. ' + body}
      onMouseEnter={show}
      onMouseLeave={hide}
      onFocus={show}
      onBlur={hide}
    >
      <span className={numeral + ' ' + tone + (expired ? ' font-normal' : '')}>
        {expired ? 'exp' : Number(reading.value)}
      </span>
      <FreshnessRing state={reading.state} size={large ? 18 : 14} />
      {pos && (
        <span
          role="tooltip"
          className="fixed z-50 w-64 -translate-y-full rounded-md border border-wb-border bg-wb-bg-elevated p-2.5 text-left shadow-lg"
          style={{ top: pos.top, right: pos.right }}
        >
          <span className="mb-1 flex items-center gap-2">
            <FreshnessRing state={reading.state} size={12} />
            <span
              className={
                'font-wb-mono text-[0.62rem] font-bold uppercase tracking-widest ' +
                TIER_TEXT[reading.state]
              }
            >
              {TIER_TITLE[reading.state]}
            </span>
          </span>
          <span className="block text-xs font-normal normal-case leading-relaxed tracking-normal text-wb-text-secondary">
            {body}
          </span>
        </span>
      )}
    </span>
  )
}

export function RingLegend() {
  return (
    <div className="flex flex-wrap items-center gap-4 text-[11px] text-wb-text-muted">
      <span className="font-wb-mono uppercase tracking-widest">
        Ring legend · annotation, does not ship
      </span>
      {[
        ['fresh', '0–1 sessions'],
        ['aging', '2–3'],
        ['stale', '4–10 · muted'],
        ['expired', 'over 10 · exp'],
        ['predates_earnings', 'any age']
      ].map(([state, range]) => (
        <span key={state} className="inline-flex items-center gap-1.5">

          <span className="text-wb-text-secondary">{TIER_TITLE[state]}</span>
          <span>{range}</span>
        </span>
      ))}
      <span className="inline-flex items-center gap-1.5">
        <span className="font-wb-mono">n/a</span>
        <span>never collected · no ring</span>
      </span>
    </div>
  )
}

export function ivGate(stock) {
  // Mirrors the deriveSignal table in docs/spec/features/us-98-ivr-staleness-tiers.md:
  // an unusable or absent reading is unknown, never a failed numeric comparison.
  if (stock.ivrMin === null) return { verdict: 'none', label: null }
  const reading = stock.ivRank
  const condition = 'IVR ≥ ' + stock.ivrMin
  if (reading === null || reading.state === 'expired')
    return { verdict: 'unknown', label: 'IV unavailable', condition }
  if (reading.state === 'stale')
    return { verdict: 'unknown', label: 'IV too old to judge', condition }
  if (reading.state === 'predates_earnings')
    return { verdict: 'unknown', label: 'IV predates earnings', condition }
  if (Number(reading.value) >= stock.ivrMin) return { verdict: 'met', label: null, condition }
  return { verdict: 'unmet', label: 'IV low', condition }
}

export function evaluate(stock) {
  const gate = ivGate(stock)
  const reasons = [
    stock.blocker,
    gate.label,
    stock.contract === null && stock.blocker === null ? 'No qualifying contract' : null
  ].filter(Boolean)
  const ready = stock.contract !== null && reasons.length === 0
  const reason = ready
    ? gate.verdict === 'met'
      ? 'All conditions met'
      : 'Screening criteria met'
    : reasons.join(' · ')
  return { ...stock, gate, ready, reason }
}

export function GateBadge({ gate }) {
  if (gate.verdict === 'none') return <Badge>No personal IV condition</Badge>
  if (gate.verdict === 'met') return <Badge color="var(--wb-green)">{gate.condition} · met</Badge>
  if (gate.verdict === 'unmet') return <Badge>{gate.condition} · not met</Badge>
  return <Badge color="var(--wb-text-muted)">{gate.condition} · unknown</Badge>
}

export function ReadingNote({ stock }) {
  // What the current reading can and cannot decide; only the unusable states earn a note.
  const reading = stock.ivRank
  if (reading === null)
    return (
      <AlertBox variant="info">
        No IV rank has been collected for {stock.ticker}. Until one exists, an IV condition cannot
        be judged and this stock cannot reach Meets criteria on it.
      </AlertBox>
    )
  if (reading.state === 'expired')
    return (
      <AlertBox variant="warning">
        The last IV rank for {stock.ticker} is {reading.ageTradingDays} trading days old and has
        expired. It is treated as no reading: it cannot satisfy “IVR ≥ {stock.ivrMin}” and the
        IV-rank floor does not apply. Age this old means the collector has been failing for this
        name — check the snapshot diagnostics.
      </AlertBox>
    )
  if (reading.state === 'stale')
    return (
      <AlertBox variant="warning">
        IV rank {Number(reading.value)} is {reading.ageTradingDays} trading days old. It is shown
        for context but is treated as unknown: it cannot satisfy “IVR ≥ {stock.ivrMin}” even though
        the value is above the threshold. A reading older than one session in steady state means
        collection has been failing for {stock.ticker}.
      </AlertBox>
    )
  if (reading.state === 'predates_earnings')
    return (
      <AlertBox variant="warning">
        IV rank {Number(reading.value)} was observed before {stock.ticker} reported earnings. IV
        re-prices through a print, so this reading is unusable regardless of age and cannot satisfy
        an IV condition. It will clear after the next collection.
      </AlertBox>
    )
  return null
}

export function AddStock({ entries, onAdd, onCancel }) {
  const {
    register,
    handleSubmit,
    setError,
    formState: { errors }
  } = useForm({ resolver: zodResolver(addSchema), defaultValues: { ticker: '', note: '' } })
  return (
    <SectionCard header="Add a stock to watch">
      <form
        className="flex flex-col gap-4 p-5"
        onSubmit={handleSubmit((values) => {
          if (entries.some((s) => s.ticker === values.ticker)) {
            setError('ticker', { message: values.ticker + ' is already on your watchlist' })
            return
          }
          onAdd({
            ticker: values.ticker,
            name: 'New stock',
            price: '—',
            change: '—',
            ivRank: null,
            ivrMin: null,
            blocker: 'Not screened yet',
            note: values.note || 'No thesis yet.',
            conditions: [],
            earnings: 'Not checked',
            contract: null
          })
        })}
      >
        <div className="grid gap-4 md:grid-cols-[160px_1fr]">
          <Field label="Ticker" htmlFor="add-ticker" error={errors.ticker?.message}>
            <Input id="add-ticker" placeholder="e.g. AMZN" {...register('ticker')} />
          </Field>
          <Field label="Why are you interested?" htmlFor="add-note" error={errors.note?.message}>
            <Input
              id="add-note"
              placeholder="Optional thesis or research note"
              {...register('note')}
            />
          </Field>
        </div>
        <p className="text-xs text-wb-text-muted">
          New stocks start in Stocks of interest until screened. Their IV rank reads n/a until the
          next collection runs. Entry-condition editing is a separate interaction in this concept.
        </p>
        <div className="flex gap-2">
          <Button type="submit" size="sm">
            Add to watchlist
          </Button>
          <Button type="button" variant="ghost" size="sm" onClick={onCancel}>
            Cancel
          </Button>
        </div>
      </form>
    </SectionCard>
  )
}

            <Button size="sm" onClick={() => onReview(stock)}>
              Review trade →
            </Button>
          </div>
        </SectionCard>
      ) : (
        <div className="flex flex-col gap-3">
          <AlertBox variant="warning">
            {stock.reason}. This stock stays on your watchlist while you wait.
          </AlertBox>
          {stock.contract !== null && (
            <p className="text-xs leading-relaxed text-wb-text-muted">
              A qualifying put exists ({stock.contract.strike} · {stock.contract.expiry} ·{' '}
              {stock.contract.period} yield) but is held back until the IV condition can be judged
              on a usable reading.
            </p>
          )}
        </div>
      )}
    </div>
  )
}

        ' ' +
        stock.contract.strike +
        ' put, ' +
        stock.contract.expiry +
        ', mark ' +
        stock.contract.mark +
