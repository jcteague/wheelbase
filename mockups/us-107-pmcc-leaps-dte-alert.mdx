# US-107: PMCC LEAPS roll-window alert

_The dashboard management queue, same frame as US-106, now with a row about the **LEAPS** rather than the short call. **XYZ** holds an $80 LEAPS expiring 2027-09-17 and a $112 short call expiring 2027-08-20. As the valuation date advances the LEAPS crosses 60 DTE and a row opens; the panel under the queue plots the LEAPS on a day axis so the window is visible._

## Where this appears

- **Management queue** (US-51) — the alert row: ticker, MED pill, the PMCC badge US-106 introduced, a summary that starts with "LEAPS", and the Review position action.
- **Position detail** — unchanged. Review position lands on the XYZ detail page; the roll itself is US-105.

## A time rule, not a price rule

US-106 watches the stock against the short strike. This rule watches the calendar against the LEAPS. It has the shape of MANAGEMENT_WINDOW: it opens at 60 DTE inclusive, refreshes its summary as the days count down, and resolves only when the LEAPS is rolled (US-105) or the position closes. It fires with or without a short call open, which widens US-106's "short call open" evaluability rule: a PMCC is evaluated whenever its LEAPS is open.

## Acceptance Criteria States

- **outside-window**: valuation 2027-07-09, LEAPS 70 DTE. Not in the queue; the panel shows the LEAPS to the right of the 60-day line.
- **at-60**: 2027-07-19, exactly 60 DTE. Row opens at MED — the boundary is inclusive, like 21 DTE and 5 DTE on the wheel.
- **in-window**: 2027-07-20, 59 DTE. The same row, one day further along; the summary refreshed in place, nothing refired.
- **short-expiring**: 2027-08-18. The short call has 2 DTE so EXPIRATION_IMMINENT co-fires at HIGH above the MED LEAPS row. Each row names its own leg; neither reads the other's.
- **leaps-only**: 2027-09-15. The short expired worthless on 2027-08-20 and only the LEAPS remains, at 2 DTE. The PMCC is still evaluated, the LEAPS row is open, and the stale EXPIRATION_IMMINENT row for the expired short resolved.
- **rolled**: 2027-07-20 after a US-105 roll to $85 expiring 2028-01-21. 185 DTE, so the alert resolved and nothing refired.
- **expiration-unreadable**: the LEAPS expiration cannot be read this run. The rule skips with reason missing_leaps_dte and the existing row stays open with its last summary rather than resolving on missing data.

export const LEAPS = { strike: 80, expiration: '2027-09-17', debit: 25.0 }
export const SHORT = { strike: 112, expiration: '2027-08-20', premium: 2.1 }
export const WINDOW_DTE = 60

export const PRESETS = [
  { key: 'outside-window', label: 'outside window', today: '2027-07-09' },
  { key: 'at-60', label: 'at 60 DTE', today: '2027-07-19' },
  { key: 'in-window', label: 'in window', today: '2027-07-20', previous: '2027-07-19' },
  { key: 'short-expiring', label: 'short expiring', today: '2027-08-18', previous: '2027-07-19' },
  { key: 'leaps-only', label: 'LEAPS only', today: '2027-09-15', previous: '2027-07-19', shortOpen: false },
  {
    key: 'rolled',
    label: 'rolled',
    today: '2027-07-20',
    previous: '2027-07-19',
    leaps: { strike: 85, expiration: '2028-01-21', debit: 23.5 }
  },
  {
    key: 'expiration-unreadable',
    label: 'expiration unreadable',
    today: '2027-07-20',
    previous: '2027-07-19',
    unreadable: true
  }
]

export const WHEEL_ROWS = [
  {
    ticker: 'AAPL',
    phase: 'CSP_OPEN',
    urgency: 'medium',
    rule: 'MANAGEMENT_WINDOW',
    summary: '20 DTE remaining — review for roll or close'
  },
  {
    ticker: 'GOOGL',
    phase: 'CC_OPEN',
    urgency: 'low',
    rule: 'PROFIT_TARGET',
    summary: '54.0% of max profit captured — consider closing'
  }
]

export const URGENCY_ORDER = { high: 0, medium: 1, low: 2 }

export const money = (value) => `$${value.toFixed(2)}`

export const dte = (expiration, today) =>
  Math.round((Date.parse(expiration) - Date.parse(today)) / 86400000)

export function inDays(days) {
  if (days === 0) return 'today'
  if (days === 1) return 'in 1 day'
  return `in ${days} days`
}

export function leapsSummary(days, strike) {
  return `LEAPS expires ${inDays(days)} at ${money(strike)} strike — review for roll or close`
}

export function evaluate(preset) {
  const leaps = preset.leaps ?? LEAPS
  const shortOpen = preset.shortOpen !== false
  const today = preset.today
  const leapsDte = dte(leaps.expiration, today)
  const shortDte = shortOpen ? dte(SHORT.expiration, today) : null
  const hadAlert = preset.previous !== undefined
  const previousDte = hadAlert ? dte(LEAPS.expiration, preset.previous) : null
  const common = { leaps, shortOpen, today, leapsDte, shortDte, hadAlert, previousDte }

  if (preset.unreadable) {
    return {
      ...common,
      fires: false,
      skipped: true,
      summary: leapsSummary(previousDte, LEAPS.strike),
      status: 'kept-open',
      imminent: false
    }
  }
  const fires = leapsDte >= 0 && leapsDte <= WINDOW_DTE
  return {
    ...common,
    fires,
    skipped: false,
    summary: fires ? leapsSummary(leapsDte, leaps.strike) : null,
    status: fires ? 'open' : hadAlert ? 'resolved' : 'none',
    imminent: shortOpen && shortDte >= 0 && shortDte <= 5
  }
}

export function queueRows(model) {
  const rows = [...WHEEL_ROWS]
  if (model.status === 'open' || model.status === 'kept-open') {
    rows.push({
      ticker: 'XYZ',
      pmcc: true,
      leg: 'LEAPS',
      urgency: 'medium',
      rule: 'PMCC_LEAPS_ROLL_WINDOW',
      summary: model.summary
    })
  }
  if (model.imminent) {
    rows.push({
      ticker: 'XYZ',
      pmcc: true,
      leg: 'short call',
      urgency: 'high',
      rule: 'EXPIRATION_IMMINENT',
      summary: `Expires in ${model.shortDte} days at ${money(SHORT.strike)} strike`
    })
  }
  return rows.sort((a, b) => URGENCY_ORDER[a.urgency] - URGENCY_ORDER[b.urgency])
}

      <div className="flex flex-col gap-1">
        <span className="text-base font-bold text-wb-text-primary">{row.ticker}</span>
        <UrgencyPill urgency={row.urgency} />
      </div>
      {row.pmcc ? (
        <Badge className="gap-[5px] rounded text-[0.7rem] px-2 py-0.5">
          <span className="h-[5px] w-[5px] shrink-0 rounded-full bg-wb-gold" />
          PMCC
        </Badge>
      ) : (
        <PhaseBadge phase={row.phase} variant="short" />
      )}
      <span className="text-sm leading-relaxed text-wb-text-secondary">{row.summary}</span>
      <div className="flex justify-self-end gap-2">
        <button
          type="button"
          className="rounded-lg border border-wb-gold-border bg-wb-gold-dim px-3.5 py-2.5 text-xs font-wb-mono font-bold text-wb-gold"

      </div>

}

export function LegendItem({ swatchClass, label, value, tone, shape = 'square' }) {
  const swatchShape =
    shape === 'dot' ? 'h-4 w-4 rounded-full border-2 border-wb-bg-base' : 'h-3 w-3 rounded-sm'
  return (
    <div className="contents">
      <span className="flex h-4 w-4 items-center justify-center">
        <span className={`inline-block shrink-0 ${swatchShape} ${swatchClass}`} />
      </span>
      <span className="text-wb-text-secondary">{label}</span>
      <span className={tone ?? 'text-wb-text-primary'}>{value}</span>
    </div>
  )
}

export function DteRuler({ model }) {
  // Day axis from today (left) out to 200 days. The 60-day window is shaded;
  // the LEAPS sits at its DTE, the short call at its own when open.
  const max = 200
  const pct = (days) => `${Math.max(0, Math.min((days / max) * 100, 100))}%`
  const leapsMarker = model.skipped ? model.previousDte : model.leapsDte
  const leapsTone = model.skipped
    ? 'bg-wb-text-muted'
    : model.fires
      ? 'bg-wb-gold'
      : 'bg-wb-green'

  return (
    <div className="flex flex-col gap-3 px-4 py-4">
      <div className="relative h-14">
        <div className="absolute inset-x-0 top-5 h-1.5 rounded-full bg-wb-bg-elevated" />
        <div
          className="absolute top-5 h-1.5 rounded-l-full bg-wb-gold-dim"
          style={{ left: 0, width: pct(WINDOW_DTE) }}
        />
        <div className="absolute top-3 h-6 w-px bg-wb-gold" style={{ left: pct(WINDOW_DTE) }} />
        <div className="absolute top-2 h-8 w-0.5 bg-wb-text-primary" style={{ left: 0 }} />
        {model.shortOpen && model.shortDte !== null ? (
          <div
            className="absolute top-4 h-3 w-3 -translate-x-1/2 rotate-45 border border-wb-bg-base bg-wb-text-secondary"
            style={{ left: pct(model.shortDte) }}
          />
        ) : null}
        {leapsMarker === null ? null : (
          <div
            className={`absolute top-3.5 h-4 w-4 -translate-x-1/2 rounded-full border-2 border-wb-bg-base ${leapsTone} ${model.skipped ? 'opacity-50' : ''}`}
            style={{ left: pct(leapsMarker) }}
          />
        )}
        <div className="absolute inset-x-0 top-10 flex justify-between text-[10px] text-wb-text-muted">
          <span>today · {model.today}</span>
          <span>{max} days out</span>
        </div>
      </div>
      <div className="mt-2 grid grid-cols-[auto_auto_1fr] items-center gap-x-3 gap-y-1.5 border-t border-wb-border pt-3 text-[10px] text-wb-text-muted">
        <LegendItem swatchClass="bg-wb-gold-dim" label="Roll window" value={`0 to ${WINDOW_DTE} DTE, inclusive`} />
        <LegendItem
          shape="dot"
          swatchClass={`${leapsTone} ${model.skipped ? 'opacity-50' : ''}`}
          label={model.skipped ? 'LEAPS, last known' : 'LEAPS'}
          value={
            model.skipped
              ? `${money(LEAPS.strike)} · expiration unreadable · was ${model.previousDte} DTE`
              : `${money(model.leaps.strike)} · ${model.leaps.expiration} · ${model.leapsDte} DTE`
          }
          tone={model.fires ? 'text-wb-gold' : undefined}
        />
        <LegendItem
          swatchClass="bg-wb-text-secondary rotate-45"
          label="Short call"
          value={
            model.shortOpen
              ? `${money(SHORT.strike)} · ${SHORT.expiration} · ${model.shortDte} DTE`
              : 'none open — expired 2027-08-20'
          }
        />
      </div>
    </div>
  )
}

export function Explanation({ model, presetKey }) {
  if (model.status === 'kept-open') {
    return (
      <AlertBox variant="warning">
        The LEAPS expiration could not be read this evaluation. The rule skipped with reason
        missing_leaps_dte, so the open alert keeps its last summary instead of resolving. It will
        re-evaluate on the next tick.
      </AlertBox>
    )
  }
  if (presetKey === 'rolled') {
    return (
      <AlertBox variant="success">
        LEAPS rolled to {money(model.leaps.strike)} expiring {model.leaps.expiration} (US-105). It
        now has {model.leapsDte} DTE, outside the window, so the alert resolved and nothing refired.
        A fresh alert opens with a new triggered time when the new LEAPS reaches 60 DTE.
      </AlertBox>
    )
  }
  if (model.status === 'none') {
    return (
      <AlertBox variant="info">
        The LEAPS has {model.leapsDte} days left, outside the 60-day window. Nothing to review yet.
        The wheel short-call rules do not read the LEAPS either: 70 DTE would never trip a 21-day
        management window, and if it did that would be the wrong row.
      </AlertBox>
    )
  }
  if (!model.shortOpen) {
    return (
      <AlertBox variant="error">
        Only the LEAPS is open and it expires {inDays(model.leapsDte)}. Under US-106 alone this
        position was not evaluated at all; this story makes a PMCC evaluable whenever its LEAPS is
        open, so this is the row that keeps a LEAPS from running to expiration with an empty queue.
        The short-call rules are inapplicable here, not skipped, which is why the expired short's
        EXPIRATION_IMMINENT row resolved rather than being kept open.
      </AlertBox>
    )
  }
  if (model.imminent) {
    return (
      <AlertBox variant="warning">
        Two XYZ rows, two legs. The HIGH row is the wheel's expiration rule on the short call; the
        MED row is this rule on the LEAPS. Each summary names its leg and strike so the trader can
        tell them apart from the queue. Neither rule reads the other leg.
      </AlertBox>
    )
  }
  return (
    <AlertBox variant="warning">
      Inside the roll window: the LEAPS has {model.leapsDte} days left and its time value decays
      faster from here. Review position leads to the detail page, where Roll LEAPS (US-105) is the
      action this alert points at. The summary refreshes in place each day; a dismissed row stays
      dismissed until the roll takes the LEAPS back outside the window.
    </AlertBox>
  )
}

              onClick={() => setPresetKey(entry.key)}
            />

        </div>

          Every figure is derived from the preset valuation date and the leg expirations: DTE is

          AAPL and GOOGL rows are fixed wheel alerts, there to show the PMCC rows sitting beside
