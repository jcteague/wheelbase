# US-110: PMCC screening criteria sheet

_The US-67 sheet, opened while the bench is on the **PMCC** lens. Same 460px `SheetPanel`, same header, footer, field primitives and validation posture; the groups change to what a diagonal needs. The wheel form is untouched and edits its own document._

**Fictional sample data as of Friday, September 18, 2026.** The bench behind the sheet is abbreviated to what the sheet changes: the criteria strip and the Meets criteria cards. Field layout reuses `SheetGroup`, `SheetField`, `RangeField`, `OptionalNumericField`, `Segment` and `NumericInput` from `ScreeningCriteriaForm.tsx` class for class — the plan extracts them into `criteria-fields.tsx` so both forms compose one set.

## Acceptance Criteria States

- **default** — every field at its shipped default: LEAPS Δ 0.70–0.85 and 180–540 DTE; short Δ 0.25–0.35 and 20–45 DTE; max debit 90% of width; OI ≥ 200; spread ≤ 10%; IV band off; earnings Exclude. Save enabled.
- **invalid** — LEAPS minimum DTE `40` overlaps the short window (`LEAPS minimum DTE must exceed short-call maximum DTE`), short delta inverted (`Minimum delta must be less than maximum delta`), IV floor 60 above ceiling 40 (`IV-rank floor must be less than IV-rank ceiling`). Save disabled; the reset link becomes `Fix the highlighted fields.`
- **iv band on** — both optional IV-rank inputs enabled (floor 30, ceiling 55), showing the enabled look of the two Off/On controls.
- **saved** — sheet dismissed after tightening max debit / width to 85%: the banner, the updated chip, XLF dropped from Meets criteria with `debit 87.82% of width exceeds 85%`, KO now #1.

export function Divider() {
  return <div className="h-px bg-wb-border-subtle" />
}

export function SheetGroup({ label, children }) {
  return (
    <div className="flex flex-col gap-3.5">
      <div className="font-wb-mono text-[0.62rem] uppercase tracking-[0.12em] text-wb-text-muted">
        {label}
      </div>
      {children}
    </div>
  )
}

export function SheetField({ label, caption, error, children }) {
  return (
    <div>
      <div className="text-[0.8125rem] font-semibold text-wb-text-primary">{label}</div>
      <div className="mt-1 text-[0.7rem] leading-relaxed text-wb-text-muted">{caption}</div>
      <div className="mt-2.5">{children}</div>
      {error && (
        <div className="mt-1.5 flex items-center gap-1.5 text-[0.7rem] text-wb-red">
          <span className="font-wb-mono font-bold">!</span>
          {error}
        </div>
      )}
    </div>
  )
}

export function Segment({ options, value, onChange }) {
  return (
    <div className="inline-flex gap-0.5 rounded-full border border-wb-border bg-wb-bg-elevated p-[3px]">
      {options.map((option) => {
        const active = option.value === value
        return (
          <button
            key={String(option.value)}
            type="button"
            aria-pressed={active}
            onClick={() => onChange(option.value)}
            className={
              'cursor-pointer rounded-full border-none px-3 py-1 font-wb-mono text-[0.72rem] ' +
              (active ? 'bg-wb-gold-dim font-bold text-wb-gold' : 'bg-transparent text-wb-text-secondary')
            }
          >
            {option.label}
          </button>
        )
      })}
    </div>
  )
}

export function NumericInput({ ariaLabel, value, widthClass, hasError, disabled, prefix, suffix }) {
  return (
    <span
      className={[
        'inline-flex items-center gap-1.5 rounded-md border px-2.5 py-1.5',
        widthClass,
        hasError ? 'border-wb-red' : 'border-wb-border',
        disabled ? 'bg-wb-bg-surface opacity-50' : 'bg-wb-bg-base'
      ].join(' ')}
    >
      {prefix && <span className="font-wb-mono text-[0.8rem] text-wb-text-muted">{prefix}</span>}
      <input
        type="text"
        aria-label={ariaLabel}
        readOnly
        value={value}
        disabled={disabled}
        className="w-full min-w-0 flex-1 border-none bg-transparent font-wb-mono text-[0.85rem] text-wb-text-primary outline-none"
      />
      {suffix && <span className="font-wb-mono text-[0.78rem] text-wb-text-muted">{suffix}</span>}
    </span>
  )
}

export function RangeField({ label, caption, unit, error, minLabel, maxLabel, min, max }) {
  return (
    <SheetField label={label} caption={caption} error={error}>
      <div className="flex items-center gap-2">
        <NumericInput ariaLabel={minLabel} value={min} widthClass="w-[86px]" hasError={Boolean(error)} />
        <span className="text-wb-text-muted">–</span>
        <NumericInput ariaLabel={maxLabel} value={max} widthClass="w-[86px]" hasError={Boolean(error)} />
        <span className="text-[0.72rem] text-wb-text-muted">{unit}</span>
      </div>
    </SheetField>
  )
}

export function OptionalNumericField({ label, caption, error, enabled, onToggle, value, suffix }) {
  return (
    <SheetField label={label} caption={caption} error={error}>
      <div className="flex items-center gap-3">
        <Segment
          value={enabled}
          onChange={onToggle}
          options={[
            { value: false, label: 'Off' },
            { value: true, label: 'On' }
          ]}
        />
        <NumericInput
          ariaLabel={label}
          value={value}
          widthClass="w-[104px]"
          hasError={Boolean(error)}
          disabled={!enabled}
          suffix={suffix}
        />
      </div>
    </SheetField>
  )
}
