# US-57: Global Alert Thresholds

_As a wheel trader with a preferred management style, I want to configure my default profit target percentage and management-window DTE so the app matches how I manage positions._

## Acceptance Criteria States

- **defaults**: existing 50% / 21 DTE values loaded from settings
- **customized**: trader edits to 40% / 14 DTE and sees the new behavior preview before saving
- **invalid**: inline validation errors for out-of-range values
- **saved**: confirmation banner after settings persist successfully

---

export const MONO = "'JetBrains Mono', 'Fira Mono', monospace"

export const STATES = {
  defaults: { profit: '50', dte: '21', banner: null, errors: {} },
  customized: { profit: '40', dte: '14', banner: null, errors: {} },
  invalid: {
    profit: '0',
    dte: '0',

  saved: { profit: '40', dte: '14', banner: 'Alert defaults saved', errors: {} }

      </div>

}
