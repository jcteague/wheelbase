# US-68: Promote to Trade

_As a wheel trader, I want one click to open the new-wheel form pre-filled from a screener result, confirmed against a fresh quote, so I don't re-key the trade._

## Acceptance Criteria States

- **prefilled** — promoting an AAPL screener result opens the New Wheel form with ticker `AAPL`, strike `180`, expiration `2026-08-21`, contracts `1`, and premium `2.70` filled in. The thesis is seeded from the watchlist note. A neutral note confirms the fresh quote still matches the promoted mark ($2.70). Nothing is recorded until the trader clicks **Record wheel**.
- **moved** — the form re-fetched on open and the mark drifted past the price-moved threshold (more than **both** $0.05 and 5% of the promoted mark), so a non-blocking gold banner reads _"Price moved: quoted $2.70 → now $2.50 — review before submitting."_ The premium input still holds the editable `2.70`; submit stays enabled.
- **stale** — the market is `CLOSED` (an `EXT` session shows the same warning — equity options don't trade extended hours), so the pre-filled mark is an after-hours snapshot. A gold banner warns the mark is stale and to verify before recording. Submit stays enabled.
- **offline** — the fresh-quote fetch failed, so the form degrades to the promoted snapshot: a gold banner reads _"Couldn't refresh quote — showing screener snapshot from 10:42:15."_ The form stays fully usable and submit stays enabled.
- **edited** — the trader overrode the premium to `2.65`; the derived yield recomputes (1.47% period · 14.5%/yr) while capital stays $18,000. A muted note confirms the recorded trade uses the entered price, not the screener snapshot.

Every field stays editable, exactly like the normal new-wheel form — promote pre-fills, it never locks. The premium is an **editable default** that the re-fetch never overwrites. Promote lands the trader in the form — it never places or records a trade on its own. Colors and chrome are driven by the app's `--wb-*` design tokens; the market-status pill mirrors `MarketStatusPill` (LIVE / EXT / CLOSED).

export function money(n) {
  return '$' + n.toLocaleString('en-US', { minimumFractionDigits: 0, maximumFractionDigits: 0 })
}

export function yieldHint(premium) {
  const period = (premium / 180) * 100
  const annual = period * (365 / 37)
  return period.toFixed(2) + '% period · ' + annual.toFixed(1) + '%/yr'
}
