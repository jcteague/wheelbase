# US-58: Position Alert Overrides

_As a wheel trader making ticker-specific choices, I want to override global alert thresholds for one position so I can manage that name differently without changing everything._

## Acceptance Criteria States

- **inherit**: position is using the app-wide 50% / 21 DTE defaults
- **override**: custom 25% / 14 DTE thresholds are active for one position
- **cleared**: trader has chosen to revert to global defaults
- **invalid**: inline validation when custom values are out of range

---

  return (
