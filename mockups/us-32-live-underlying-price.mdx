# US-32: Live Underlying Price on Position List

_Adds a live **Price** column to the positions table showing real-time underlying price, daily change, and a market session indicator. Powered by the `MarketDataProvider` from US-31 via a `useStockQuotes` TanStack Query hook polling every 60 s during regular hours._

## Acceptance Criteria States

- **market-open**: Regular session — green LIVE pulse dot, price + green/red change for all 3 positions
- **extended-hours**: Pre/post market — amber EXT dot, extended-hours prices shown
- **market-closed**: Weekend or after 8 PM ET — gray CLOSED dot, last closing prices
- **stale-data**: Last successful poll > 5 min ago — amber warning banner above table, amber dot replaces LIVE
- **unavailable**: TSLA returns no quote (API error) — price cell shows `—` with tooltip

export function PriceCell({ quote, unavailable }) {
  if (unavailable || quote === null) {
    return (
      <td title="Price unavailable" style={{
        fontFamily: MONO,
        padding: '10px 16px',
        borderBottom: '1px solid rgba(30,42,56,0.4)',
        verticalAlign: 'middle',
        cursor: 'help'
      }}>
        <span style={{ color: '#4a5a6a', fontSize: '0.8125rem' }}>—</span>
        <div style={{ fontSize: '0.6rem', color: '#4a5a6a', marginTop: 2 }}>unavailable</div>
      </td>
    )
  }
  return (
    <td style={{
      fontFamily: MONO,
      padding: '10px 16px',
      borderBottom: '1px solid rgba(30,42,56,0.4)',
      verticalAlign: 'middle'
    }}>
      <div style={{
        fontSize: '0.8125rem',
        fontWeight: 600,
        color: 'var(--wb-text-primary, #e6edf3)',

      }}>

        marginTop: 1
      }}>
        {quote.change}
      </div>
    </td>
  )
}
