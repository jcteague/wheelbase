# US-37 (revised): Massive + Alpaca credentials and broker environment toggle

_Settings page with two top-level sections: **Market Data (Massive)** holds a single API key, **Broker (Alpaca)** holds paired Paper + Live credentials with an active-environment toggle. The header badge tracks broker environment only — Massive shows a small connection dot beside the badge. Switching to LIVE always requires explicit confirmation; switching back to Paper does not._

## Acceptance Criteria States

- **all-configured**: Massive key set, both Alpaca paper + live configured, paper active → header shows amber **PAPER** badge + green Massive dot
- **paper-only**: Massive set, paper Alpaca set, live Alpaca empty → same header, live card shows empty inputs
- **massive-only**: Massive set, no Alpaca creds → header badge shows neutral grey **BROKER NOT CONFIGURED**
- **empty-state**: No credentials anywhere → onboarding banner appears, both sections collapsed to "Not configured"
- **switch-to-live-dialog**: User clicked Live in the broker toggle → confirmation modal overlays the page

      ) : (
        <NotConfiguredCard
          label="Broker — Alpaca"
          message="No credentials configured · market data continues to work via Massive"
        />
      )}
    </div>
  )
}
