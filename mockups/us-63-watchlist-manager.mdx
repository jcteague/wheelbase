# US-63: Watchlist Manager

_As a wheel trader, I want to maintain a watchlist of tickers (with a thesis) so the screener has a curated universe to pull chains for._

> **Stories covered:** a shared watchlist mockup organized by action on an entry (ticker + thesis + conditions). Creating an entry is **US-63** (`add` / `duplicate` / `empty` states); editing an entry is **US-69** (`edit` state); viewing the list with live Price/IVR/earnings and the derived Signal chip is **US-96** (`list` state). The states below are grouped by behavior, not by story.

## Acceptance Criteria States

- **list** — the curated watchlist as a dense table: `Ticker · Signal · Price · IVR · Thesis · Added · ✕`. Each row carries the free-text thesis plus compact condition tags (`≤ $170`, `IVR ≥ 50`, `post-earnings`, `core`). **Price** shows the last trade with the 1-day change beneath it (`▲` green / `▼` red / `·` flat); **IVR** is the IV-rank colored to match the preset thresholds (muted `< 30`, gold `30–49`, green `≥ 50`). The derived **Signal** chip — `Entry ready` / `N% away` / `IV low` / `Earnings Nd` / `No thesis` — is computed from the conditions against live price / IV-rank / earnings; when more than one gate is unmet it lists the extra one beneath (e.g. `+ IV low`), and an amber `⚠ ER Nd` warning appears on any name reporting within ~7 days **even if `post-earnings only` isn't set**. Condition tags are clickable and open the entry in the edit form. New entries land at the top.
- **add** — the add-entry form: a ticker input, quick-pick entry-condition chips (`Would own below`, `Wait for high IV`, `Post-earnings only`, `Core holding`), and a free-text thesis. Adding a value-bearing condition expands it into a labelled input — a `$` price field for `Would own below`, an `IVR ≥` field with `30 / 50 / 70` preset buttons for `Wait for high IV` — each removable with `✕`. The thesis is captured up front so the list can convey it immediately.
- **duplicate** — the add-entry form rejecting a duplicate: typing `AAPL` (already listed) surfaces the inline error `AAPL is already on the watchlist` and adds nothing.
- **edit** — the same form reused to modify an existing entry (here AAPL): the ticker is fixed, and every condition and the thesis are pre-filled and editable (e.g. change `own below $170`). Primary action is Save; the edited row is highlighted in the list. This supersedes the old thesis-only inline editor (US-69) by folding thesis + conditions into one surface.
- **empty** — the first-run empty state explaining that adding tickers is what enables the screener, with the add-entry form ready.

Condition presets map to **structured triggers** (target price, IV-rank threshold, earnings gate, always-on) while the thesis stays free text (500-char bound matches `newWheelSchema.thesis`). The **Signal** chip presumes live price / IV-rank / earnings from the market-data adapter (Epic 06) and is shown here with sample data. Colors, fonts, and chrome are driven by the app's design tokens in `src/renderer/src/index.css` (`--wb-*`). The header freshness indicator mirrors `MarketStatusPill` (`src/renderer/src/components/MarketStatusPill.tsx`); symbol validation reuses `tickerSchema`.

export function fmtPrice(n) {
  return '$' + n.toFixed(2)
}

export function conditionTags(r) {
  const tags = []
  if (r.target != null) tags.push('≤ $' + r.target)
  if (r.ivrTrigger != null) tags.push('IVR ≥ ' + r.ivrTrigger)
  if (r.postEarnings) tags.push('post-earnings')
  if (r.core) tags.push('core')
  return tags
}

export function deriveSignal(r) {
  const hasCondition = r.target != null || r.ivrTrigger != null || r.postEarnings || r.core
  if (!hasCondition) return { label: 'No thesis', tone: 'none', secondary: null }
  if (r.postEarnings && r.erDays != null && r.erDays <= 7) {
    return { label: 'Earnings ' + r.erDays + 'd', tone: 'caution', secondary: null }
  }
  const priceReady = r.target == null || r.price <= r.target
  const ivReady = r.ivrTrigger == null || r.ivr >= r.ivrTrigger
  if (priceReady && ivReady) return { label: 'Entry ready', tone: 'ready', secondary: null }
  const unmet = []
  if (!priceReady) unmet.push(((r.price / r.target - 1) * 100).toFixed(1) + '% away')
  if (!ivReady) unmet.push('IV low')
  return { label: unmet[0], tone: 'watching', secondary: unmet.slice(1).join(' · ') || null }
}

                )}

              {row.added}
            </div>
            <div style={{ textAlign: 'right' }}>
              <button
                title="Remove"
                style={{
                  width: 24,
                  height: 24,
                  borderRadius: T.r,
                  border: `1px solid ${T.border}`,

        )
      })}
    </div>
  )
}

export function Segment({ options, value, onChange }) {
  return (
    <div

    >

            key={opt.v}
            onClick={() => onChange(opt.v)}
            style={{
              padding: '5px 12px',
              borderRadius: 999,
              border: 'none',
              cursor: 'pointer',

              fontSize: '0.72rem',

              fontWeight: active ? 700 : 400
            }}
          >
            {opt.label}
          </button>
        )
      })}
    </div>
  )
}
