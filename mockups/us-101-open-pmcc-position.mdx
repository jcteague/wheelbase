# US-101: One entry point, two strategies

Click **Open Wheel**, then toggle **Standard / PMCC** in the right-hand panel. The positions screen stays underneath. Field values are fixed fictional examples; panel opening, strategy switching, dismissal, and sample recording work.

export function SampleField({ id, label, value, hint, error }) {
  return <Field label={label} htmlFor={id} hint={hint} error={error}><NumberInput id={id} value={value} readOnly hasError={Boolean(error)} /></Field>
}

  const save = () => { setRecorded({ mode, debit }); setOpen(false); trigger.current?.querySelector('button')?.focus() }
  const legs = [
