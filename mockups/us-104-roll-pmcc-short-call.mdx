# US-104: Roll the PMCC short call

_Open the **XYZ** PMCC detail page, then use **Roll Short Call**. The sheet is the same right-hand panel US-102 established for the PMCC flows — this story fills in the cash side of it: the net credit or debit, the roll label, and the effective share cost the replacement strike is measured against._

## Where this appears

- **Position detail header** — the Roll Short Call action, beside Roll LEAPS.
- **Roll Short Call sheet** — current short call, LEAPS coverage context, entry inputs, live net preview.
- **Cost-basis panel and history** (US-103) — receives one net line per roll; this mockup shows the resulting row, it does not redefine the panel.

## The coverage ruler

The one PMCC-specific device on this sheet. A wheel covered call has no coverage window — a PMCC does, and it is the difference between an income trade and a naked call. The ruler plots today, the current short, the replacement short, and the LEAPS on one axis, so the invariant US-102 owns reads as a picture before it reads as an error.

## Acceptance Criteria States

- **entry**: the sheet opens with the current short call, the LEAPS as read-only coverage, and the effective share cost of $101.20. No preview until both cash fields are filled.
- **roll-up-out**: $112 replacement, Dec 18. Net Debit $0.60 per share ($60.00 total), labelled Roll Up & Out, 42 DTE. Confirm stays available — paying to move a challenged short call is a valid choice.
- **roll-out-credit**: same $108 strike, Dec 18. Net Credit $1.20 per share ($120.00 total), labelled Roll Out.
- **below-effective-cost**: $98 replacement. Advisory warning that assignment would resolve roughly $3.70 per share below the effective share cost. Confirm stays available.
- **outlasts-leaps**: a Sep 17 2027 replacement reaches the LEAPS. Blocked by the US-102 comparator, ruler goes red, nothing is recorded.
- **rolls-in**: a Nov 13 2026 replacement expires before the current short. Blocked.
- **no-change**: same strike, same expiration. Blocked.
- **zero-cost-to-close**: a $0.00 cost to close. Blocked at the field.
- **recorded**: the linked leg pair is written, cost basis moves $21.20 to $21.80, and the history shows one net line.
- **no-short-call**: with no short call open there is nothing to roll — the header offers Sell Short Call (US-115) instead.

export function evaluate(draft) {
  const costToClose = draft.costToClose === '' ? null : Number(draft.costToClose)
  const premium = draft.premium === '' ? null : Number(draft.premium)
  const strike = draft.strike === '' ? null : Number(draft.strike)
  const expiration = draft.expiration === '' ? null : draft.expiration
  const errors = {}

  if (expiration !== null) {
    if (expiration >= LEAPS.expiration) {
      errors.expiration = 'Short call must expire before the LEAPS call.'
    } else if (expiration < SHORT.expiration) {
      errors.expiration = `Replacement expiration must be on or after the current expiration (${longDateOf(SHORT.expiration)})`
    }
  }
  if (costToClose !== null && costToClose <= 0) {
    errors.costToClose = 'Cost to close must be greater than zero'
  }
  if (premium !== null && premium <= 0) {
    errors.premium = 'Replacement premium must be greater than zero'
  }
  if (strike === SHORT.strike && expiration === SHORT.expiration) {
    errors.form = 'Roll must change the strike, the expiration, or both'
  }

  const priced = costToClose !== null && premium !== null && costToClose > 0 && premium > 0
  const net = priced ? premium - costToClose : null
  const postBasis = priced ? BASIS - net : null
  const effectiveAfter = priced ? LEAPS.strike + postBasis : null
  const complete =
    costToClose !== null && premium !== null && strike !== null && expiration !== null
  const valid = complete && Object.keys(errors).length === 0
  const shortfall =
    valid && strike < effectiveAfter ? effectiveAfter - strike : null

  return { costToClose, premium, strike, expiration, errors, net, postBasis, effectiveAfter, valid, shortfall }
}

export function rollLabel(strike, expiration) {
  const direction = strike > SHORT.strike ? 'Up' : strike < SHORT.strike ? 'Down' : null
  const later = expiration > SHORT.expiration
  const parts = [direction, later ? 'Out' : null].filter(Boolean)
  if (parts.length === 0) return null
  const strikeText =
    direction === null
      ? `same $${SHORT.strike} strike`
      : `$${SHORT.strike} to $${strike} strike`
  const dateText = later
    ? `${monthOf(SHORT.expiration)} to ${monthOf(expiration)} expiration`
    : `same ${monthOf(SHORT.expiration)} expiration`
  return `Roll ${parts.join(' & ')}: ${strikeText}, ${dateText}`
}

export function CoverageRuler({ proposed, blocked }) {
  const span = dte(LEAPS.expiration)
  const currentPct = (dte(SHORT.expiration) / span) * 100
  const proposedPct = proposed === null ? null : Math.min((dte(proposed) / span) * 100, 100)
  const tone = blocked ? 'var(--wb-red)' : 'var(--wb-gold)'

  return (
    <div className="flex flex-col gap-3 px-4 py-4">
      <div className="relative h-8">
        <div className="absolute inset-x-0 top-3 h-px bg-wb-border" />
        <div
          className="absolute top-3 h-px"
          style={{ left: 0, width: `${proposedPct ?? currentPct}%`, background: tone }}
        />
        <div className="absolute top-1.5 h-3 w-px bg-wb-text-muted" style={{ left: 0 }} />
        <div
          className="absolute top-1.5 h-3 w-px bg-wb-text-secondary"
          style={{ left: `${currentPct}%` }}
        />
        {proposedPct === null ? null : (
          <div
            className="absolute top-0 h-6 w-0.5"
            style={{ left: `${proposedPct}%`, background: tone }}
          />
        )}
        <div className="absolute top-1.5 h-3 w-px bg-wb-green" style={{ left: '100%' }} />
      </div>
      <div className="flex justify-between text-[10px] text-wb-text-muted">
        <span>today</span>
        <span className="text-wb-green">LEAPS {LEAPS.expiration} · {span} DTE</span>
      </div>
      {proposed === null ? (
        <p className="text-[11px] text-wb-text-secondary">
          Current short call expires in {dte(SHORT.expiration)} days. The LEAPS covers {span} days.
        </p>
      ) : blocked ? (
        <p className="text-[11px] text-wb-red">
          The replacement short reaches the LEAPS. Past this point the short call is naked.
        </p>
      ) : (
        <p className="text-[11px] text-wb-text-secondary">
          Replacement short at {dte(proposed)} DTE. The LEAPS still covers it by{' '}
          {span - dte(proposed)} days.
        </p>
      )}
    </div>
  )
}
