# US-67: Screening Defaults

_As a wheel trader, I want to configure the screener criteria — delta band, DTE window, liquidity gates, price ceiling, IV-rank floor, and earnings handling — so results reflect how I pick entries._

## Acceptance Criteria States

- **default** — every criterion at its shipped default (delta 0.20–0.30, DTE 30–45, min OI 500, max spread 10%, price ceiling off, IV-rank floor off, earnings **Exclude**). Save is enabled.
- **saved** — a green `Screening criteria saved` banner confirms the write; fields stay at the saved values (price ceiling off).
- **invalid** — the delta band (0.30 → 0.20) and DTE window (45 → 30) are inverted, each with an inline red error, and **Save is disabled** — mirroring the cross-field min-less-than-max validation. Price ceiling off.
- **flag** — earnings handling switched to `Flag only`, with the IV-rank floor and the optional price ceiling both toggled `On` (30 IVR / $75), showing the enabled look of the optional inputs.

Colors, fonts, and chrome are driven by the app's design tokens in `src/renderer/src/index.css` (`--wb-*`). Delta band and DTE window are paired min/max hard filters; liquidity is a hard gate; the price ceiling is off by default (an optional per-account buying-power limit — a fixed dollar ceiling on by default would silently hide large-cap names); the IV-rank floor is a soft ranking input (off by default so a low-vol regime doesn't empty results); earnings handling is the `exclude` / `flag` policy the scorer (US-65) and the earnings warning (US-70) read.

export function Segment({ options, value, onChange, size = 'md' }) {
  const pad = size === 'sm' ? '4px 10px' : '5px 12px'
  return (
    <div
      style={{
        display: 'inline-flex',
        gap: 2,
        padding: 3,
        borderRadius: 999,
        border: `1px solid ${T.border}`,
        background: T.elevated
      }}
    >
      {options.map((opt) => {
        const active = value === opt.v
        return (
          <button
            key={opt.v}
            onClick={() => onChange(opt.v)}
            style={{
              padding: pad,
              borderRadius: 999,
              border: 'none',
              cursor: 'pointer',
              fontFamily: T.mono,
              fontSize: '0.72rem',
              background: active ? T.goldDim : 'transparent',
              color: active ? T.gold : T.text2,
              fontWeight: active ? 700 : 400
            }}
          >
            {opt.label}
          </button>
        )
      })}
    </div>
  )
}
