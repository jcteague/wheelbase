# US-103: PMCC cost basis

Open the **XYZ** PMCC detail page. The **Cost basis** panel sits below the two leg panels from US-101 and reconciles in one line of arithmetic: LEAPS cost to date minus short-call credits to date. Step the lifecycle control to watch it move as each leg event lands — and to watch the effective share cost re-anchor to the new strike after the LEAPS roll.

## Where this appears

- **PMCC detail page** — the Cost basis panel and the per-event history below it.
- **Positions list** — US-101's "Initial net debit" cell becomes the running **Cost basis** total.
- Wheel positions are untouched: no PMCC panel, no effective share cost.

## Acceptance Criteria States

- **entry**: the two opening legs give $23.00 per share; the $200.00 credit is listed as open, not as profit.
- **short-expired**: the credit becomes realized and cost basis does not move.
- **new-short**: a subsequent short call at $1.80 drops cost basis to $21.20.
- **short-roll**: a roll at a $0.60 net debit lifts it to $21.80 and posts one net line, not two gross lines.
- **leaps-roll**: a $2.50 net credit drops it to $19.30, and the effective share cost re-anchors to the new $85.00 strike.
- **free**: credits exceed the LEAPS cost, so cost basis reads -$0.40 and the position shows as fully paid for.

Prototype controls at the bottom switch between one and three contracts and add US-101's $1.00 per-leg opening fees, covering the quantity and fee criteria.

export const signed = (value, places) =>
  `${value < 0 ? '-' : ''}$${Math.abs(value).toFixed(places)}`

export const money = (value) => signed(value, 2)

export const perShareText = (value) => {
  const rounded = Math.round(value * 100) / 100
  return Math.abs(value - rounded) < 1e-9 ? signed(value, 2) : signed(value, 4)
}

export function ledgerThrough(stageKey, contracts, withFees) {
  const stage = STAGES.find((entry) => entry.key === stageKey)
  const cut = EVENTS.findIndex((event) => event.id === stage.through)
  const applied = EVENTS.slice(0, cut + 1)
  const shares = SHARES_PER_CONTRACT * contracts
  const fee = (event) => (withFees ? (event.fee ?? 0) : 0)

const longCost = applied
.filter((event) => event.leg === 'long')
.reduce((sum, event) => sum + event.perShare _ shares + fee(event), 0)
const credits = applied
.filter((event) => event.leg === 'short')
.reduce((sum, event) => sum - event.perShare _ shares - fee(event), 0)
const strike = applied.reduce((current, event) => event.strikeAfter ?? current, 0)
const basis = longCost - credits

return {
stage,
applied,
shares,
longCost,
credits,
basis,
strike,
basisPerShare: basis / shares,
longCostPerShare: longCost / shares,
creditsPerShare: credits / shares,
effectiveShareCost: strike + basis / shares,
recovered: (credits / longCost) \* 100,
free: basis <= 0
}
}
