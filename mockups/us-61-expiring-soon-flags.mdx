# US-61: Expiring Soon Flags

_As a wheel trader scanning the dashboard and calendar, I want positions expiring within 7 days to stand out before they become critical._

## Acceptance Criteria States

- **dashboard** — the positions table golds the DTE and pins an `Expiring soon` flag on any position at 7 DTE or less (AAPL · 7d, MSFT · 4d). NVDA at 8 DTE and the `HOLDING_SHARES` TSLA row stay quiet.
- **calendar** — expiring-soon dates carry a gold ring on the month grid; the day-detail panel repeats the `Expiring soon` flag and golds the DTE, so the warning language is identical to the dashboard.
- **clean** — flip _Flags_ to `Off` to see the same surfaces with the extra emphasis removed; this is exactly how positions at 8+ DTE (and holding-shares) already render.

Colors, fonts, and chrome are driven by the app's design tokens in `src/renderer/src/index.css` (`--wb-*`). Phase colors mirror `src/renderer/src/lib/phase.ts`, the gold DTE emphasis reuses `isDteUrgent` (`DTE_URGENT_THRESHOLD = 7`) from `src/renderer/src/lib/dte.ts`, and the calendar grid + day detail track `CalendarMonthGrid`/`CalendarDayDetail`. `HOLDING_SHARES` positions have no option expiration, so they never flag and never appear on the calendar.

            value={surface}
            onChange={setSurface}
            options={[
              { v: 'dashboard', label: 'Dashboard' },
              { v: 'calendar', label: 'Calendar' }
            ]}
          />
        </div>
        <div style={{ display: 'flex', alignItems: 'center', gap: 10 }}>
          <SectionLabel>Flags</SectionLabel>
          <Segment
            value={flags ? 'on' : 'off'}
            onChange={(v) => setFlags(v === 'on')}
            options={[
              { v: 'on', label: 'On' },
              { v: 'off', label: 'Off (clean)' }
            ]}
          />
        </div>
      </div>

      <Shell surface={surface}>
        {surface === 'dashboard' ? (
          <DashboardView flags={flags} />
        ) : (
          <CalendarView flags={flags} selected={selected} onSelect={setSelected} />
        )}
      </Shell>
    </div>
  )
}
