# Extract: us-117

<!-- generated -->

## Summary

Bugfix. The position cockpit's Context strip rendered `NaN%` for IV because the preload and
renderer type mirrors declared a **required** `greeks.iv: string` that no producer has ever
written, while the real figure — `impliedVolatility` — was already correct in the main process
and already crossing the IPC at runtime, but invisible to the renderer because no type declared
it. `buildCockpitInput` did `parseFloat(snapshot.greeks.iv)` → `parseFloat(undefined)` → `NaN`,
and `ContextStrip`'s `iv != null` guard let it through, because `NaN != null` is `true`.

This story deletes `greeks.iv` from all three type declarations and promotes `impliedVolatility`
to a sibling of `greeks`, hardens the Alpaca mapper so a non-finite figure is dropped rather than
stringified as `"NaN"`, routes every renderer parse through one finite-guard helper, and makes
the IV cell render `—` instead of `NaN%`. The Context strip's existing render gate is
deliberately left alone, preserving US-34's shipped behaviour. Done: the IV cell shows `28.4%`
when Alpaca supplies it, `—` when it does not, and `NaN%` is unreachable from any of the five
figures. No schema change, no migration, no new dependency. (Source: `plans/us-117/plan.md`)

## Architecture Decisions

### ADR: Implied volatility is a sibling of `greeks`, never a member of it

- **Decision:** `impliedVolatility?: string` sits beside `greeks` on the IPC snapshot, and
  `greeks.iv` is deleted from `src/preload/index.d.ts`, `src/renderer/src/api/market-data.ts`
  and `CockpitInput.greeks` in `src/renderer/src/lib/verdict.ts`. The preload and renderer types
  become exact mirrors of `OptionSnapshot` in
  `src/main/integrations/market-data-provider.ts`: `greeks` optional, `impliedVolatility`
  optional, both 4dp decimal strings.
- **Why:** it is already the main-process shape and the truthful one — implied volatility is a
  property of the quote, not of the Greeks. Alpaca supplies it independently of the Greeks
  block, so nesting it would force a contract with IV but no Greeks to discard its IV. Making
  the mirrors match the producer removes the drift that caused the defect rather than papering
  over it.
- **Alternatives considered:** populate `greeks.iv` in the mapper — rejected; it would make the
  app's own type disagree with the vendor shape, keep IV hostage to a complete Greek set
  (roughly half of quoted contracts have none), and leave `greeks` and `iv` with different
  availability rules under one required key.
- **Source:** `plans/us-117/research.md`

### ADR: Optionality expresses absence on the wire; required-and-nullable inside the renderer

- **Decision:** on the IPC-crossing types the fields are optional — `greeks?: {...}` and
  `impliedVolatility?: string` — not `string | null`. On the renderer-internal `CockpitInput`
  they are **required and nullable**: `greeks: {...} | null` and
  `impliedVolatility: number | null`.
- **Why:** the producer *omits* the key rather than sending null (`mapOptionQuote` assigns
  conditionally), so `?` is what actually crosses the wire, and `strictNullChecks` forces every
  consumer to handle `undefined` exactly as it would `null`. Inside the renderer the opposite is
  right: making `impliedVolatility` required-and-nullable means `buildCockpitInput` *cannot
  compile* without deciding what the value is. That is the precise shape of the original bug — a
  required field no producer filled — inverted so the compiler catches it.
- **Alternatives considered:** `string | null` on the IPC types — rejected; it would describe a
  null the producer never sends, and every consumer would have to handle both anyway.
- **Source:** `plans/us-117/research.md`

### ADR: Non-finite figures are dropped at the producer and logged at the adapter

- **Decision:** `mapOptionQuote` and `isCompleteGreeks` switch from `typeof x === 'number'` to
  `Number.isFinite(x)`, so a `NaN`/`Infinity` figure is **omitted** rather than stringified. The
  mapper stays pure and silent; it also exports a pure `nonFiniteFigures(snap): string[]` naming
  the fields that were present but unusable.
  `AlpacaMarketDataProvider.getOptionSnapshot` logs
  `logger.warn({ contract, fields }, 'alpaca_option_snapshot_non_finite_figure')` when that
  array is non-empty.
- **Why:** `typeof NaN === 'number'` is `true`, so both predicates admitted `NaN` and
  `new Decimal(NaN).toFixed(4)` emitted the **string `"NaN"`** across the IPC. "Fix the
  producer, not the formatter" — a guard at the render would hide `NaN%` while leaving the cell
  empty forever. Splitting drop-from-map and log-from-adapter keeps the mapper's own contract
  ("No I/O — every function here is total and side-effect free") intact while still satisfying
  the AC's warn, and it matches how the file already handles a bad chain key (pure
  `mapChainEntry` returns null, the adapter logs it).
- **Alternatives considered:** (a) `console.warn` from the renderer — rejected, the renderer has
  no logging channel at all and adding one for a single call site is a new convention for no
  gain; (b) logging in both layers — rejected, two log lines per defect. `getOptionChainSnapshot`
  deliberately stays silent: 161 contracts per underlying would make it noise.
- **Source:** `plans/us-117/research.md`

### ADR: Greeks stay all-or-nothing; implied volatility is independent

- **Decision:** if any one of delta/gamma/theta/vega is missing or non-finite, the whole `greeks`
  block is absent — the existing `isCompleteGreeks` rule, now hardened. Implied volatility is
  evaluated separately and can be present with no Greeks, or absent with a full set. The
  renderer mirrors the rule in `parseAllOrNothing`.
- **Why:** it is the rule the producer already enforces, and it keeps `CockpitInput.greeks` a
  single nullable object rather than four independently-nullable numbers. Four nullable Greeks
  would ripple through `computeVerdict`, `computeDistance` and `RiskSnapshot`, all of which read
  `input.greeks.delta` as a plain number — a large blast radius for a 3-point defect fix.
- **Alternatives considered:** per-Greek nullability — rejected on blast radius; it also
  contradicts the mapper's own "a partial greek set is unusable … dropped wholesale" rule.
- **Source:** `plans/us-117/research.md`

### ADR: The Context strip keeps its all-or-nothing gate; only the IV cell learns to dash

- **Decision:** `ContextStrip` keeps both early returns (`if (!input.greeks) return null` and
  `if (!theta) return null`). The strip renders only when the contract has a complete Greek set.
  Inside it, the **IV cell** dashes independently — implied volatility is a sibling of `greeks`,
  so a contract with Greeks and no IV shows a real dashed cell.
- **Why:** it preserves the shipped US-34 acceptance criterion that a Greek-less contract shows
  no strip at all (`e2e/position-cockpit.spec.ts`, `ContextStrip.spec.tsx`). This story is a
  defect fix scoped to one broken figure; inverting a shipped AC from another story is a product
  change that belongs to that story.
- **Consequence:** two ACs are satisfied **in spirit, not literally**. "No snapshot at all reads
  as absent → the IV cell reads `—`" and the Scenario Outline's "the `<label>` cell reads `—`"
  both name a cell that does not exist when there are no Greeks. They are read as *nothing
  broken is shown*, and asserted as: the strip is absent **and** `NaN` appears nowhere on the
  page **and** the cockpit itself rendered, so "absent" cannot be satisfied by a blank page or a
  crash. Reviewer note, recorded for honesty: *every* IV scenario is in fact conditional on a
  complete Greek set under the retained gate, not only these two.
- **Alternatives considered:** always render, dashing every empty cell — the literal reading of
  the AC, and it would surface IV on the roughly half of contracts Alpaca gives no Greeks for
  (`contracts: 161, withGreeks: 87`). Rejected here to keep US-34's AC intact; worth its own
  story.
- **Source:** `plans/us-117/research.md`

### ADR: One shared finite-parse helper at the renderer edge

- **Decision:** `parseFinite(value: string | null | undefined): number | null` in
  `src/renderer/src/lib/format.ts` returns `null` for absent input and for any parse that is not
  `Number.isFinite`. `buildCockpitInput` routes all six figures through it — the four Greeks,
  `currentMid`, and `underlying`.
- **Why:** `underlying` already hand-rolled the same behaviour as `parseFloat(x) || null`; it
  was written once and not applied to its five neighbours, which is the "same hazard sits on the
  other three Greeks" observation in the story. One named helper closes all six. It is a second
  line of defence only — the producer guard is what makes the number *appear*. `|| null` is
  deliberately not reused: it also swallows a legitimate `0`, which is a valid delta.
- **Alternatives considered:** a `Number.isFinite` check inside `ContextStrip`'s formatter alone
  — rejected; it would dash the cell forever while the mapping stayed broken.
- **Source:** `plans/us-117/research.md`

## Contracts

### `OptionSnapshot` — the shape that crosses the IPC

Source of truth (unchanged by this story), `src/main/integrations/market-data-provider.ts`:

```typescript
export type OptionSnapshot = {
  bid: string
  ask: string
  mid: string
  lastTrade: string
  openInterest: number | null
  volume: number | null
  greeks?: { delta: string; gamma: string; theta: string; vega: string }
  impliedVolatility?: string // 4dp decimal string, e.g. '0.2840'
  timestamp: string
}
```

Both hand-written mirrors are brought into exact agreement with it:

| Mirror                              | Before                                            | After                                                   |
| ----------------------------------- | ------------------------------------------------- | ------------------------------------------------------- |
| `src/preload/index.d.ts`            | `greeks` required, with required `iv: string`     | `greeks?` without `iv`; `impliedVolatility?: string`    |
| `src/renderer/src/api/market-data.ts` | `OptionGreeks.iv` required; `greeks` required    | `iv` deleted; `greeks?`; `impliedVolatility?: string`   |

Availability rules, enforced by the producer:

- `greeks` is present **only** when all four of delta/gamma/theta/vega are finite numbers. A
  partial or non-finite set is dropped whole.
- `impliedVolatility` is present **only** when Alpaca sent a finite number. It is independent of
  `greeks` — either may be present without the other.
- Neither is ever `null` and neither is ever the string `"NaN"`.

### `nonFiniteFigures` — pure producer helper

```typescript
/** Field names that Alpaca sent as a number but which cannot be used (NaN / Infinity). */
export function nonFiniteFigures(snap: AlpacaOptionSnapshot): string[]
```

Returns `[]` for a clean snapshot and for one that simply **omits** a figure — an absent field is
not a defect, it is the normal case. Returns e.g. `['impliedVolatility']` or
`['greeks.delta', 'greeks.vega']` when a field is present with a non-finite value. Pure: no
logging, no I/O.

`src/renderer/src/lib/verdict.ts`:

```typescript

greeks: { delta: number; theta: number; gamma: number; vega: number } | null
```

### Context strip display rules

The render gate is **unchanged** — both early returns stay. What changes is the IV cell only:

| Cell  | Value                                 | Sub                                                            | Changed |
| ----- | ------------------------------------- | -------------------------------------------------------------- | ------- |
| Theta | `fmtMoney(thetaDollar)` + `/d`        | `{yieldPct}% yield over {dte}d`                                | no      |
| IV    | `(iv * 100).toFixed(1)` + `%`, or `—` | `implied vol`, or `rank {ivRank}` when the prop is passed      | **yes** |
| Vega  | `fmtMoney(vega * 100)`                | `per 1% IV move`                                               | no      |
| Gamma | `abs(gamma).toFixed(3)`               | `elevated near expiry` when elevated, else `delta sensitivity` | no      |

A dashed IV cell takes the default `text-wb-text-primary`, not a severity token. Theta, Vega and
Gamma are unreachable with a non-finite value because `greeks` is all-or-nothing: one bad Greek
nulls the whole block, and a null block means no strip.

## Decisions & Tradeoffs

- **The two IPC type mirrors remain hand-maintained copies with no structural link** — the
  direct cause of this defect. Each now carries a comment naming the source of truth, but a
  comment is a convention, not a mechanism; `typecheck` still cannot see a mirror disagreeing
  with its source. Adding the link was explicitly out of scope.
- **`ContextStrip`'s guard is `iv != null && Number.isFinite(iv)`.** The `!= null` looks
  redundant (`Number.isFinite(null)` is `false`) but is load-bearing: `Number.isFinite` is not a
  TypeScript type predicate, so without it `iv * 100` does not compile.
- **`fmtMoney`, `pnlColor` and `pnlClass` still call bare `parseFloat`** on strings from the same
  IPC boundary. Converting them is a behaviour change (`fmtMoney(undefined)` yields `"$NaN"`
  today) and belongs to its own story.
- **`PositionCockpit.tsx`'s HOLDING_SHARES card still uses bare `parseFloat`** for the basis and
  spot price, so an unparseable value renders `+$NaN` — the same defect class, one panel up.
  Deferred as a behaviour change.
