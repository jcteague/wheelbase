## Architecture Decisions

### ADR: Subsume US-34 (Greeks Panel) into a Cockpit Redesign
- **Decision:** Do not ship `GreeksPanel` as a standalone section card. Replace `PositionDetailContent`'s body wholesale with `<PositionCockpit>` — a composite that puts the verdict pill on top, the delta gauge and distance thermometer in a "Risk snapshot" card, the four Greek metrics in a "Context" strip, and the previously-prominent Open Leg / Cost Basis stat rows inside collapsible drawers (collapsed by default). Notes, the closed-position banner, and `CloseCspForm` remain below the cockpit untouched.
- **Why:** The US-34 acceptance criteria call for "delta with severity color", "theta as $/day", "IV as %", "no panel when no active leg" — these are satisfied by the new `ContextStrip` + `RiskSnapshot` + verdict pill more comprehensively than a flat panel. The cockpit gives a trader a single glanceable answer ("ACT NOW") rather than five raw numbers they have to interpret.
- **Alternatives considered:**
  - Ship `GreeksPanel` as originally specced — works but leaves the verdict-routing logic for a later story and duplicates greek-severity reasoning across two components.
  - Add the verdict pill above the existing stat sections — keeps the old layout's information density; loses the cockpit's tight stack.
- **Source:** `plans/us-34/plan.md`, `docs/epics/06-stories/US-34-greeks-display.md`

### ADR: Deterministic Verdict via Pure `computeVerdict` (No React)
- **Decision:** All verdict routing lives in `src/renderer/src/lib/verdict.ts` as pure functions consuming a `CockpitInput` shape. The component layer never decides "which verdict?" — it calls `computeVerdict(input)` and renders the result. The same module exports `computePnl`, `computeDistance`, `computeThetaYield`, `deltaSeverity`, and `SEVERITY_COLOR`.
- **Why:** Keeps the rules unit-testable in isolation (14 verdict-logic tests cover every branch and threshold). Mirrors the architecture rule for `src/main/core/` engines being pure — applied at the renderer layer for management logic.
- **Alternatives considered:** Inlining the precedence chain into `PositionCockpit.tsx` — couples rule changes to component re-renders and forces every threshold change to touch JSX.
- **Source:** `plans/us-34/plan.md`, `plans/us-34/research.md`

### ADR: Verdict Precedence (First Match Wins)
- **Decision:** Six-rule precedence chain inside `computeVerdict`, evaluated top-down:
  1. `dte ≤ 3 && |delta| > 0.50` → **ACT NOW** (red)
  2. `pnl.pct ≥ 50` → **TARGET HIT** (green)
  3. `deltaSeverity === 'danger' || dist.isITM` → **CONSIDER ROLL** (red)
  4. `deltaSeverity === 'warning'` → **WATCH** (gold)
  5. `dte ≤ 21 && dte > 7` → **WATCH** (gold)
  6. otherwise → **HOLD** (green)
  No active leg → `SHARES_VERDICT` constant ("NO ACTIVE LEG", sky). No greeks data → `HOLD` with sub "Awaiting market data".
- **Why:** Imminent expiration with ITM exposure (rule 1) trumps everything else — the trader needs to act today. Profit-target (rule 2) overrides delta concerns because if 50% is captured, closing is cheap regardless of severity. Danger delta or ITM (rule 3) ranks above warning bands because either alone is a roll signal. Warning delta (rule 4) and the 21-7 DTE window (rule 5) both reduce to "WATCH" — close enough to expiry to be on radar but not yet actionable.
- **Source:** `plans/us-34/plan.md` (Area 1), `plans/us-34/data-model.md`

### ADR: DTE-Aware Delta Severity Shift
- **Decision:** When `dte ≤ 7`, all delta-severity thresholds drop by 0.05 (i.e. the trader gets one severity tier worse than the static thresholds would say). CSP base: warning ≥ 0.30, danger > 0.45. CC base: warning ≥ 0.35, danger > 0.50. With the shift, a CSP at |delta|=0.41 with dte=5 is `danger` because the danger threshold drops to 0.40.
- **Why:** Gamma rises sharply near expiry, so the same delta represents materially higher assignment risk at 5 DTE than at 30 DTE. A constant threshold under-warns near expiration.
- **Source:** `plans/us-34/data-model.md`, `plans/us-34/plan.md` (Area 1 test case `deltaSeverity — DTE-aware shift`)

## Acceptance Criteria

### Cockpit ACs (defined in `plans/us-34/plan.md`)

- **AC-1 Verdict computation** — `computeVerdict(input)` deterministically routes to one of six labels based on the precedence chain (ACT NOW → TARGET HIT → CONSIDER ROLL → WATCH (delta) → WATCH (DTE window) → HOLD). Greeks-absent → HOLD with sub "Awaiting market data". No-active-leg → NO ACTIVE LEG (`SHARES_VERDICT`).
- **AC-2 DTE-aware delta severity** — When `dte ≤ 7`, every delta-severity threshold drops by 0.05 (CSP danger 0.45 → 0.40; CSP warning 0.30 → 0.25; CC danger 0.50 → 0.45; CC warning 0.35 → 0.30). The `DeltaGauge` label suffix flips from `DELTA` to `DELTA · TIGHT` when `dte ≤ 7`.
- **AC-3 Verdict block layout** — Container has a tinted-gradient background derived from `verdict.color` at runtime (via `color-mix()`). Top row shows the ticker (large, sans-serif), a phase pill (background/border/color tinted from `phaseColor`), and a key-facts strip (strike in gold, DTE in red when ≤3 / gold when ≤7, underlying price). Verdict + P&L row uses a two-column grid (`minmax(280px, 1.1fr) 1fr`) when `pnl` is present, single-column when null. The verdict pill is a rounded full pill with a colored dot, the label in mono-uppercase tracking, and the `verdict.sub` reason rendered as a 14.5px sans-serif sub-line.
- **AC-4 Delta gauge** — Default size 108px, stroke width 6px, clockwise arc fill (`-rotate-90` on the SVG), `strokeLinecap="round"`, `stroke-dashoffset` transition 0.4s ease. Center shows `absDelta.toFixed(2)` at 22px bold in the severity color; below it sits `DELTA` (or `DELTA · TIGHT` if `dte ≤ 7`) in 9px mono-tracked muted text.
- **AC-5 Distance thermometer** — Track is a multi-stop `linear-gradient` using `color-mix()` for the gradient stops (cannot be expressed as a Tailwind class); height 14px, border-radius 7px. Strike marker is a thin vertical line at the centre (50%, 60% opacity). Underlying marker is a small rounded rectangle whose `left` percentage is clamped to `[0%, 100%]` based on `dist.pct` normalised against the range. Label row beneath: 9px mono, muted, with the strike label centred. Dollar headline above the track: 26px bold mono in the severity color.
- **AC-6 Context strip** — Four columns (Theta / IV / Vega / Gamma) in a `grid grid-cols-4 gap-px bg-wb-border` grid, each cell `bg-wb-surface p-3.5 px-4.5`. Theta shows `computeThetaYield(...)` as `$X.XX/d` and goes green when `yieldPct ≥ 50`. IV shows `(iv × 100).toFixed(1) + '%'`; the sub-line reads `rank N` when `ivRank` is provided. Vega shows `fmtMoney(vega × 100)` (dollar value per 1% IV move). Gamma shows `|gamma|.toFixed(3)`; cell turns gold when `dte ≤ 7 && |gamma| ≥ 0.04` with sub "elevated near expiry", otherwise sub reads "delta sensitivity". `ContextStrip` returns `null` when greeks are absent.
- **AC-7 Collapsible drawers** — Two drawers below the risk/context cards: "Leg reference" (5 or 6 fields depending on whether a snapshot is present) and "Cost basis & history" (2 stat fields + optional leg-history table). Both render a chevron (▶ closed / ▼ open) + title + "N fields" right-label header. Collapsed by default (`aria-expanded=false`) when an active leg exists; the "Cost basis & history" drawer is `defaultOpen` when there's no active leg. Clicking the header toggles. Implemented via shadcn `<Collapsible>` for accessible keyboard toggle + `aria-expanded`.
- **AC-8 No-active-leg state** — `HOLDING_SHARES` (or any state without `activeLeg`) renders `<VerdictBlock>` with `SHARES_VERDICT` and `pnl={null}` (P&L panel hidden), plus the "Cost basis & history" drawer `defaultOpen`. `RiskSnapshot`, `ContextStrip`, and "Leg reference" drawer are not rendered.
- **AC-9 Live data binding** — `PositionDetailPage` calls both `useOptionSnapshots(legSummaries)` and `useStockQuotes([position.ticker])`. Greeks/mid arrive through the option-snapshot polling cache; underlying price arrives through the stock-quote stream. Snapshot-absent → no `<RiskSnapshot>` or `<ContextStrip>` (graceful null); cockpit still renders verdict + drawers.
- **AC-10 Existing surfaces preserved below the cockpit** — Notes `<SectionCard>`, closed-position banner, and `<CloseCspForm>` (when `phase === 'CSP_OPEN' && activeLeg`) all render below `<PositionCockpit>` inside `PositionDetailContent`. ## Decisions & Tradeoffs
